第17讲 · 卤素　氯及其化合物的转化关系 · 缺口真题训练

联动缺口：G15 与量有关的离子方程式（先后反应型） · 卤素递变与离子检验 · 卤素互化物与氯的价类转化　｜　全部选自高考真题
一缺口速览2分钟
  • G15 · 与量有关的离子方程式（先后反应型）：Cl₂ 遇到多种还原性离子时，按"先强后弱"依次反应。记忆两条链——还原性：I⁻＞Fe²⁺＞Br⁻＞Cl⁻；氧化性：Cl₂＞Br₂＞Fe³⁺＞I₂。所以 FeBr₂ 中通少量 Cl₂ 只氧化 Fe²⁺，过量才把 Br⁻ 一起氧化；FeI₂ 中通少量（或等物质的量）Cl₂ 只氧化 I⁻。
  • 卤素递变规律：氧化性 Cl₂＞Br₂＞I₂，与水、与碱反应都由易到难；I₂ 与 Fe 反应只生成 FeI₂，Cl₂、Br₂ 能把 Fe 氧化到 +3；氟无正价，F₂ 与水反应放出 O₂；HF 是弱酸且能腐蚀玻璃。
  • 卤素离子检验三法：① AgNO₃ 沉淀法——AgCl 白、AgBr 淡黄、AgI 黄，均不溶于稀 HNO₃；② 置换—萃取法——氯水＋CCl₄，下层呈紫红（I₂）；③ 氧化—淀粉法——I⁻ 遇氯水变蓝。
  • 卤素互化物与氯的转化：IBr、ICl、BrCl——非金属性弱的一方显正价（IBr 中 I 为 +1、Br 为 −1），与 H₂O、NaOH 反应价态不变（非氧化还原）；氯的"价—类"二维图把 Cl₂、HCl、HClO、ClO₂、ClO₃⁻ 串成一张网。

核心题1 · 一个"过量"，决定谁被氧化
【2019·海南·高考真题·T11（多选）】
本课要做（文字题）能正确表示下列反应的离子方程式为（　　）
A．向 FeBr₂ 溶液中通入过量 Cl₂：2Fe²⁺＋Cl₂＝2Fe³⁺＋2Cl⁻
B．向碳酸钠溶液中通入少量 CO₂：CO₃²⁻＋CO₂＋H₂O＝2HCO₃⁻
C．向碘化钾溶液中加入少量双氧水：3H₂O₂＋I⁻＝IO₃⁻＋3H₂O
D．向硫化钠溶液中通入过量 SO₂：2S²⁻＋5SO₂＋2H₂O＝3S↓＋4HSO₃⁻
🧭 任务卡（同桌讨论 3 分钟）

① FeBr₂ 溶液里有哪两员还原性"大将"？它们的还原性谁强谁弱？

② 题目写的是"过量 Cl₂"——方程式里应该出现谁被氧化？A 项漏了什么？

③ C 项 H₂O₂ 氧化 I⁻，产物是 I₂ 还是 IO₃⁻？

④ D 项过量 SO₂ 通入 Na₂S 溶液，最终生成了什么单质？

📚 解决本任务需要的知识

① 还原性 I⁻＞Fe²⁺＞Br⁻＞Cl⁻；氧化性 Cl₂＞Br₂＞Fe³⁺＞I₂

② 过量／少量决定反应终点——过量氧化剂把能氧化的全部氧化

③ H₂O₂ 把 I⁻ 氧化为 I₂，不是 IO₃⁻

④ SO₂ 与 S²⁻ 归中生成 S；少量 CO₂ 通入 Na₂CO₃ 生成 HCO₃⁻

🔑 全题"金钥匙"：做"与量有关"的离子方程式，先问一句——谁过量？过量到什么程度？再看还原性顺序，把该氧化的全部氧化，一个都不能落下。
显示四段详解（讨论完再展开）
✅ 正确答案：BD

🧭 思路点拨

四项都是离子方程式正误判断，逐项走"反应物→产物→配平→守恒"这条流水线；涉及"量"的选项，先确定少量/过量对应谁的终点。

📌 逐项详解

A：FeBr₂ 中 Fe²⁺、Br⁻ 都有还原性，通入过量 Cl₂ 时两者都被氧化，正确写法为 2Fe²⁺＋4Br⁻＋3Cl₂＝2Fe³⁺＋2Br₂＋6Cl⁻，漏掉 Br⁻ 被氧化，错；

B：少量 CO₂ 通入 Na₂CO₃ 溶液生成 NaHCO₃，CO₃²⁻＋CO₂＋H₂O＝2HCO₃⁻，正确；

C：H₂O₂ 把 I⁻ 氧化为 I₂（不是 IO₃⁻），应为 H₂O₂＋2H⁺＋2I⁻＝I₂＋2H₂O，错；

D：过量 SO₂ 与 S²⁻ 归中生成 S：2S²⁻＋5SO₂＋2H₂O＝3S↓＋4HSO₃⁻，正确。

⚠ 易错提醒

①"过量 Cl₂"是本题最大陷阱——只氧化 Fe²⁺ 是少量 Cl₂ 的答案；②H₂O₂ 作氧化剂时还原产物是 H₂O，不能把 I⁻ 直接氧化到 IO₃⁻；③SO₂ 过量时产物写成 HSO₃⁻ 而不是 SO₃²⁻。

📐 规律总结

G15 的核心就一句话：先强后弱，量定终点。FeBr₂ 与 Cl₂ 有三种情形——少量只氧化 Fe²⁺；等物质的量时 Fe²⁺ 全氧化、Br⁻ 部分氧化；过量则两者全氧化。

三个方向任选：改量（把"过量"改成"等物质的量"，重写方程式）· 改体系（换成 FeI₂＋Cl₂）· 改设问（给出 n(FeBr₂):n(Cl₂)=1:1，写方程式）

核心题2 · 等物质的量：这份 Cl₂"刚好够"氧化谁　〔本讲板演题〕
【2023·浙江6月选考·T9】
本课要做（文字题）下列反应的离子方程式正确的是（　　）
A．碘化亚铁溶液与等物质的量的氯气：2Fe²⁺＋2I⁻＋2Cl₂＝2Fe³⁺＋I₂＋4Cl⁻
B．向次氯酸钙溶液中通入足量二氧化碳：ClO⁻＋CO₂＋H₂O＝HClO＋HCO₃⁻
C．铜与稀硝酸：Cu＋4H⁺＋NO₃⁻＝Cu²⁺＋NO↑＋2H₂O
D．向硫化钠溶液中通入足量二氧化硫：S²⁻＋SO₂＋H₂O＝S↓＋HSO₃⁻
🧭 任务卡（同桌讨论 2 分钟）

① FeI₂ 溶液中 I⁻ 与 Fe²⁺ 谁先被氧化？1 mol FeI₂ 里两种离子的物质的量各是多少？

② "等物质的量 Cl₂"——按电子守恒算一算，这份 Cl₂ 够氧化哪一种离子？A 项错在哪？

③ 次氯酸钙溶液里通足量 CO₂，产物是 HClO＋HCO₃⁻ 还是 HClO＋CO₃²⁻？为什么？

📚 解决本任务需要的知识

① 还原性 I⁻＞Fe²⁺——FeI₂ 溶液中 I⁻ 先被氧化

② 算"量"：1 mol FeI₂ 含 2 mol I⁻ ＋ 1 mol Fe²⁺；1 mol Cl₂ 得 2 mol 电子，恰好氧化 2 mol I⁻

③ 足量 CO₂ 与 ClO⁻ 生成 HCO₃⁻（酸性 H₂CO₃＞HClO＞HCO₃⁻）

④ Cu 与稀 HNO₃：3Cu＋8H⁺＋2NO₃⁻＝3Cu²⁺＋2NO↑＋4H₂O

🔑 全题"金钥匙"：算"量"的两把尺子——还原性顺序定先后，电子守恒定量。先排顺序，再用"得电子总数＝失电子总数"算到底够不够。
显示四段详解（讨论完再展开）
✅ 正确答案：B

🧭 思路点拨

A 项先排先后（I⁻ 先于 Fe²⁺），再用电子守恒定量；B、D 项考"足量/少量"对产物的影响；C 项查配平。

📌 逐项详解

A：还原性 I⁻＞Fe²⁺，等物质的量 Cl₂ 先氧化 I⁻——1 mol Cl₂ 恰好氧化 2 mol I⁻，Fe²⁺ 不动，正确写法 2I⁻＋Cl₂＝I₂＋2Cl⁻，错；

B：足量 CO₂ 与 Ca(ClO)₂ 溶液反应生成 HClO 和 HCO₃⁻（酸性 H₂CO₃＞HClO，HClO 不能把 HCO₃⁻ 再变成 CO₃²⁻），正确；

C：铜与稀硝酸未配平，应为 3Cu＋8H⁺＋2NO₃⁻＝3Cu²⁺＋2NO↑＋4H₂O，错；

D：足量 SO₂ 与 S²⁻ 归中，应为 2S²⁻＋5SO₂＋2H₂O＝3S↓＋4HSO₃⁻，错。

⚠ 易错提醒

①FeI₂ 中 I⁻ 先于 Fe²⁺（与 FeBr₂ 中 Fe²⁺ 先于 Br⁻ 相反）；②"足量 CO₂"生成 HCO₃⁻，"少量 CO₂"生成 CO₃²⁻ 残留——产物的酸式/正式，取决于气体的量。

📐 规律总结

把两题并起来记：FeBr₂：Fe²⁺先；FeI₂：I⁻先——顺序取决于还原性强弱；数量关系一律用电子守恒算。这是 G15 缺口的全部家底。

⭐ 板演互评
任务：写出 "等物质的量 Cl₂ 通入 FeI₂ 溶液" 的离子方程式，并在旁边用一句话写出"为什么先氧化 I⁻ 而不是 Fe²⁺"。
🎯 踩点给分表（点开）
踩点（照这张表给分）分值常见错法（说错的那份最值钱）
① 先判断还原性顺序：I⁻ 强于 Fe²⁺3′把 Fe²⁺ 当成先被氧化
② 用"等物质的量"算出：1 mol Cl₂ 恰好氧化 2 mol I⁻3′当成 Cl₂ 过量，把 Fe²⁺ 也一起氧化
③ 方程式写对：2I⁻＋Cl₂＝I₂＋2Cl⁻（配平、电荷守恒）3′漏配平，或把 Fe²⁺ 写进方程式
④ 一句话理由说清：顺序由还原性强弱决定1′只答"因为题目说等量"，没回到还原性顺序

三个方向任选：改比例（n(FeI₂):n(Cl₂)=4:5，写方程式）· 改体系（把 Ca(ClO)₂ 换成 NaClO 溶液通少量 CO₂）· 改设问（判断"足量 SO₂ 通入 Na₂S 溶液只生成 S 和 HSO₃⁻"是否正确）

核心题3 · IBr：卤素互化物里，谁是"正价"的那一个
【2022·北京·高考真题】
本课要做（文字题）碘和溴可以形成卤素互化物 IBr（一氯化碘的同类物），下列关于 IBr 的说法错误的是（　　）
A．I 与 Br 的电负性不同，形成极性共价键，IBr 属于共价化合物
B．IBr 中 I 为 +1 价，可被还原为 I⁻ 或 I₂，可作强氧化剂
C．IBr＋H₂O＝HBr＋HIO 中 I、Br 的化合价均未变化，IBr 既不是氧化剂也不是还原剂
D．IBr 与 NaOH 溶液反应生成 NaI 和 NaBrO
🧭 任务卡（同桌讨论 2 分钟）

① I 和 Br 谁的非金属性强？那么 IBr 中谁是正价、谁是负价？

② IBr 与水反应时，I、Br 的化合价变了吗？它算不算氧化剂？

③ 类比 Cl₂＋2NaOH＝NaCl＋NaClO＋H₂O，IBr 与 NaOH 应该生成哪两种盐？

📚 解决本任务需要的知识

① 非金属性 Br＞I → IBr 中 Br 为 −1、I 为 +1（弱的一方显正价）

② 卤素互化物的性质类似卤素单质，可类比 Cl₂ 与水、碱的反应

③ 与 H₂O、NaOH 反应价态不变，属非氧化还原反应

④ 盐要"正价配负价"：IBr＋2NaOH＝NaBr＋NaIO＋H₂O

🔑 全题"金钥匙"：卤素互化物记一句——"强者得电子（显负价）、弱者失电子（显正价）"；水解、碱解只要价态不变，就不是氧化还原反应。
显示四段详解（讨论完再展开）
✅ 正确答案：D

🧭 思路点拨

先定 IBr 中两元素的价态（Br 非金属性强→Br 为 −1、I 为 +1），再逐项检查"性质描述"与"产物书写"是否与这个价态自洽。

📌 逐项详解

A：I 与 Br 电负性不同，共用电子对偏移，形成极性共价键，IBr 是共价化合物，正确；

B：IBr 中 I 为 +1 价，可被还原为 I⁻ 或 I₂，可作氧化剂，正确；

C：IBr＋H₂O＝HBr＋HIO 中 Br 仍为 −1、I 仍为 +1，价态不变、非氧化还原，正确；

D：与 NaOH 反应应生成 NaBr（Br 为 −1）和 NaIO（I 为 +1），写成 NaI 与 NaBrO 就把价态弄反了，错误，选 D。

⚠ 易错提醒

①卤素互化物中非金属性弱的显正价（IBr 中 I 为 +1）；②水解/碱解是非氧化还原反应，产物里元素的价态必须与反应前一致——这是判断题的"照妖镜"；③别把 IBr 当作"碘和溴简单相加"。

📐 规律总结

卤素互化物（IBr、ICl、BrCl）通式 XX′ₙ，性质介于两种卤素单质之间；判断产物的唯一依据是价态守恒。同族推理：ICl 与 NaOH 生成 NaCl 和 NaIO。

三个方向任选：换互化物（ICl、BrCl 与 NaOH 反应）· 换介质（IBr 通入 KI 溶液，写出方程式）· 换设问（判断 IBr 与水的反应是否为氧化还原反应并说明理由）

过关1 · 一步接一步，哪条转化链真的走得通
【2020·江苏·高考真题·T10】

下列选项所示的物质间转化均能实现的是（　　）

A．NaCl(aq) →电解 Cl₂(g) →石灰水 漂白粉(s)

B．NaCl(aq) →CO₂(g) NaHCO₃(s) →加热 Na₂CO₃(s)

C．NaBr(aq) →Cl₂(g) Br₂(aq) →NaI(aq) I₂(aq)

D．Mg(OH)₂(s) →HCl(aq) MgCl₂(aq) →电解 Mg(s)

显示四段详解
✅ 正确答案：C

🧭 思路点拨

每一步都要问"反应物、条件、产物是否成立"——尤其是卤素置换（氧化性强弱）与"电解的是什么状态"。

📌 逐项详解

A：制漂白粉要用石灰乳（Ca(OH)₂ 浓度足够），石灰水中 Ca(OH)₂ 溶解度太小，第一步转化不成立；

B：向 NaCl 溶液中通 CO₂ 不反应（碳酸酸性弱于盐酸），不成立；

C：Cl₂＋2NaBr＝2NaCl＋Br₂，Br₂＋2NaI＝2NaBr＋I₂，两步都是"强氧化性单质置换弱氧化性单质"，均能实现，正确；

D：电解 MgCl₂ 水溶液得到的是 Mg(OH)₂、H₂、Cl₂，制 Mg 必须电解熔融 MgCl₂，不成立。

⚠ 易错提醒

①"石灰水"与"石灰乳"只有一字之差，却是制漂白粉的关键；②电解制活泼金属一律用熔融盐/熔融氧化物，水溶液电解得不到金属单质。

📐 规律总结

卤素置换的判据只有一条：氧化性强的单质能置换氧化性弱的——Cl₂＞Br₂＞I₂，对应离子还原性 I⁻＞Br⁻＞Cl⁻。

过关2 · 氯水的平衡：稀释、加盐、加酸，往哪边走
【2022·浙江6月选考·T19】

关于反应 Cl₂(g)＋H₂O(l) ⇌ HClO(aq)＋H⁺(aq)＋Cl⁻(aq)　ΔH＜0，达到平衡后，下列说法不正确的是（　　）

A．升高温度，氯水中的 c(HClO) 减小

B．氯水中加入少量醋酸钠固体，上述平衡正向移动，c(HClO) 增大

C．取氯水稀释，c(Cl⁻)/c(HClO) 增大

D．取两份氯水，分别滴加 AgNO₃ 溶液和淀粉 KI 溶液，若前者有白色沉淀，后者溶液变蓝色，可以证明上述反应存在限度

显示四段详解
✅ 正确答案：D

🧭 思路点拨

逐项判断"改变条件→平衡怎么移动→浓度怎么变"；D 项换一个角度：要证明"存在限度"，必须说明反应物与生成物同时存在。

📌 逐项详解

A：正反应放热（ΔH＜0），升温平衡逆向移动，且 HClO 受热易分解，c(HClO) 减小，正确；

B：加入 CH₃COONa，CH₃COO⁻ 结合 H⁺ 使 c(H⁺) 减小，平衡正向移动，c(HClO) 增大，正确；

C：稀释时上述平衡正向移动，同时 HClO 自身的电离平衡（HClO⇌H⁺＋ClO⁻）也正向移动，使 c(HClO) 减小得更多，故 c(Cl⁻)/c(HClO) 增大，正确；

D：加 AgNO₃ 有白色沉淀只说明生成了 Cl⁻；加淀粉 KI 溶液变蓝只说明溶液中存在强氧化性微粒——而 Cl₂ 和 HClO 都有强氧化性，无法证明反应物与生成物共存，也就不能证明反应存在限度，错误，选 D。

⚠ 易错提醒

①证明"可逆反应存在限度"必须有反应物与生成物同时存在的直接证据（如一分为二设计实验），只有一个方向的证据不够；②稀释氯水时"c(HClO) 减小得更多"是判断 C 项的关键。

📐 规律总结

氯水是"多平衡体系"：Cl₂＋H₂O 的歧化平衡＋HClO 的电离平衡＋水的电离平衡。凡涉及"稀释/加酸碱盐"，都要把相关平衡一起写出来再判断。

过关3 · 往氯水里加点什么，漂白能力反而变强
【2016·上海·高考真题】

向新制氯水中加入少量下列物质，能增强溶液漂白能力的是（　　）

A．碳酸钙粉末　B．稀硫酸　C．氯化钙溶液　D．二氧化硫水溶液

显示四段详解
✅ 正确答案：A

🧭 思路点拨

氯水的漂白能力由 HClO 的浓度决定——凡是能让 Cl₂＋H₂O⇌HCl＋HClO 正向移动、且不消耗 HClO 的操作，都能增强漂白能力。

📌 逐项详解

A：CaCO₃ 与氯水中的盐酸反应，消耗 H⁺，使上述平衡正向移动，c(HClO) 增大（CaCO₃ 不与 HClO 反应），漂白能力增强，选 A；

B：加稀硫酸使 c(H⁺) 增大，平衡逆向移动，c(HClO) 减小；

C：CaCl₂ 溶液只稀释氯水，c(HClO) 减小；

D：SO₂ 有还原性，会与 HClO 发生氧化还原反应把 HClO 消耗掉，漂白能力下降。

⚠ 易错提醒

①CaCO₃ 与 HClO 不反应（碳酸、次氯酸都是弱酸，但盐酸酸性更强）——这是本选项成立的前提；②SO₂ 与 HClO 反应是"强还原剂＋强氧化剂"，不是"漂白叠加"。

📐 规律总结

氯水体系的一切调节都回到同一个平衡：Cl₂＋H₂O⇌HCl＋HClO——加碱（或碳酸盐）右移、加酸左移、加还原剂直接消耗 HClO。
