  • E04 · Cu⁺的不稳定性与歧化：Cu⁺ 在水溶液中站不住脚，会自己"一半升、一半降"——Cu₂O＋2H⁺＝Cu＋Cu²⁺＋H₂O（现象：溶液变蓝＋红色固体）。稳定 Cu⁺ 三招：生成沉淀（CuCl）／形成配合物（[CuCl₂]⁻、[Cu(NH₃)₄]⁺）／非水环境。
  • S11 · 配合物的结构与稳定性：CuSO₄ 溶液滴加氨水——先出现 Cu(OH)₂ 蓝色沉淀，氨水过量后沉淀溶解，得深蓝色 [Cu(NH₃)₄]²⁺；配位键由 N 提供孤对电子。
  • EX11 · 配合物制备实验：从溶液到纯品三步——过滤 → 洗涤 → 晾干；证明"是晶体"用 X 射线衍射，看明锐的衍射峰。电镀三要素：镀件作阴极接负极、镀层金属作阳极、电解液含镀层金属离子。
  • G26 · 竞争反应与共存 / 铜与氧化性酸：铜与浓硫酸、浓硝酸、稀硝酸三个方程式必须零失误；Fe³⁺ 可氧化 Cu（2Fe³⁺＋Cu＝2Fe²⁺＋Cu²⁺），由此可设计"Fe³⁺ 催化＋通 O₂"的绿色制 CuSO₄ 路线。

核心题1 · 棉花四站：铜丝插进热浓硫酸，一路各查什么　〔本讲板演题〕
【2022·广东·高考真题·T5】
本课要做（文字题）若将铜丝插入热浓硫酸中进行如图（a~d 均为浸有相应试液的棉花）所示的探究实验，下列分析正确的是（　　）
A．Cu 与浓硫酸反应，只体现 H₂SO₄ 的酸性
B．a 处变红，说明 SO₂ 是酸性氧化物
C．b 或 c 处褪色，均说明 SO₂ 具有漂白性
D．试管底部出现白色固体，说明反应中无 H₂O 生成
🧭 任务卡（同桌讨论 3 分钟）

① 把这个反应的化学方程式写出来——浓硫酸在这道题里当了"几个角色"？

② a、b、c、d 四处棉花各是什么试液？各用来说明 SO₂ 的什么性质？

③ 试管底部的白色固体是什么？为什么不是蓝色的 CuSO₄·5H₂O？

📚 解决本任务需要的知识

① Cu＋2H₂SO₄(浓) ＝Δ CuSO₄＋SO₂↑＋2H₂O——浓硫酸体现 酸性 ＋ 强氧化性

② SO₂：酸性氧化物、有漂白性、有还原性

③ 检验分工：品红褪色看漂白性，酸性 KMnO₄ 褪色看还原性

④ 无水 CuSO₄ 白色、CuSO₄·5H₂O 蓝色（用来验水）

🔑 全题"金钥匙"：见到"褪色"先分清是漂白还是氧化——品红（有机色素·漂白性）与 酸性 KMnO₄（强氧化剂·还原性）是两回事，绝不能一句"漂白"打包。
显示四段详解（讨论完再展开）
✅ 正确答案：B

🧭 思路点拨

先定反应：铜＋浓硫酸（加热）只放出 SO₂，不放出 H₂；再看装置：四处棉花是从左到右的"现象→性质"对应链，逐个核对说法与现象是否对得上。

📌 逐项详解

A：生成 CuSO₄ 体现酸性，生成 SO₂ 体现强氧化性——"只体现酸性"错；

B：a 处紫色石蕊变红，是因为 SO₂ 溶于水生成酸，说明 SO₂ 是酸性氧化物，对；

C：b 处品红褪色＝漂白性，c 处酸性 KMnO₄ 褪色＝SO₂ 被氧化（还原性），两者性质不同，错；

D：白色固体是无水 CuSO₄——正因为浓硫酸有吸水性，把反应生成的 H₂O 吸走了，反过来证明有水生成，"无 H₂O"错。

⚠ 易错提醒

①"只体现酸性"是经典错项：氧化还原反应中酸往往一身两职（酸性＋氧化性）；②无水 CuSO₄ 白色、遇水变蓝，可检验水；CuSO₄·5H₂O 才是蓝色晶体。

📐 规律总结

"铜丝插酸"三件套必须默写到零失误：浓硫酸（Δ）→SO₂、浓硝酸→NO₂、稀硝酸→NO；装置题的通用解法——从左到右把每一站的现象与性质一一对应。

⭐ 板演互评
任务：写出 "铜丝插入热浓硫酸中" 的化学方程式，以及 "铜丝插入稀硝酸中" 的离子方程式，并各用一句话说明酸体现出什么性质。
🎯 踩点给分表（点开）
踩点（照这张表给分）分值常见错法（说错的那份最值钱）
① 浓硫酸：Cu＋2H₂SO₄(浓)＝CuSO₄＋SO₂↑＋2H₂O（配平、标 Δ、标 ↑）3′漏写加热条件；或写成了稀硫酸的式子
② 稀硝酸：3Cu＋8H⁺＋2NO₃⁻＝3Cu²⁺＋2NO↑＋4H₂O（配平、电荷守恒）3′写成 Cu＋2H⁺＝Cu²⁺＋H₂↑（把硝酸当成非氧化性酸）
③ 性质归属：浓硫酸＝酸性＋强氧化性；硝酸＝氧化性（＋酸性）3′漏掉"强氧化性"，或说浓硫酸只体现酸性
④ 一句话说清产物差异：出 SO₂／NO 而不是 H₂1′只说"浓度不同"，没回到氧化性上

三个方向任选：换酸（浓 H₂SO₄ → 稀 HNO₃，看现象变不变）· 换尾气（把 d 处棉花改成 NaOH 溶液与气球）· 换设问（改成"写出该反应离子方程式并说明浓硫酸作用"）

核心题2 · 价类二维图：铜比钠多出的那条"价态线"
【2023·广东·高考真题·T10】
本课要做（文字题）部分含 Na 或含 Cu 物质的分类与相应化合价关系如图所示。下列推断不合理的是（　　）
A．可存在 c→d→e 的转化
B．能与 H₂O 反应生成 c 的物质只有 b
C．新制的 d 可用于检验葡萄糖中的醛基
D．若 b 能与 H₂O 反应生成 O₂，则 b 中含共价键
🧭 任务卡（同桌讨论 2 分钟）

① 横轴、纵轴各表示什么？a~e 每个点可能是谁——Na 系列写一套，Cu 系列再写一套。

② 图中哪几个点只能属于 Cu、不能属于 Na？为什么？

③ 新制 Cu(OH)₂ 检验葡萄糖的醛基，靠的什么现象？产物里铜是几价？

📚 解决本任务需要的知识

① 价类二维图：横＝物质类别，纵＝化合价

② Na 只有 0／+1 价，Cu 有 0／+1／+2 三种价态

③ 颜色：Cu₂O 砖红、CuO 黑、Cu(OH)₂ 蓝

④ Na₂O 与 Na₂O₂ 都能与水反应生成 NaOH；Na₂O₂ 中 O 为 −1 价、含 O—O 键

🔑 全题"金钥匙"：价类图两步走——先"定坐标"（横类别、纵价态），再"定物质"；判断"只有 b 能"这类话，只要再找出一个反例就能否掉。
显示四段详解（讨论完再展开）
✅ 正确答案：B

🧭 思路点拨

同一张图可以读两套物质：Na 系列 a＝Na、b＝Na₂O（或 Na₂O₂）、c＝NaOH；Cu 系列 a＝Cu、b＝Cu₂O（+1）、d＝Cu(OH)₂、e＝CuO（+2）。先定物质，再逐项验说法。

📌 逐项详解

A：c→d→e 即 NaOH＋CuSO₄→Cu(OH)₂，Cu(OH)₂ ＝Δ CuO＋H₂O，转化存在，合理；

B：能与 H₂O 反应生成 c（NaOH）的不止 b——Na₂O 和 Na₂O₂ 都能，"只有 b"错，选 B；

C：新制 Cu(OH)₂ 可检验葡萄糖中的醛基，加热生成砖红色 Cu₂O，合理；

D：若 b 能与 H₂O 反应生成 O₂，则 b 是 Na₂O₂——其中含 O—O 共价键（还有离子键），合理。

⚠ 易错提醒

①Na₂O₂ 是"过氧化物"：O 为 −1 价，含共价键＋离子键，别当成普通碱性氧化物；②题目问"不合理"，选的是错的推断，方向别读反；③Cu₂O 中铜是 +1 价，不是 +2。

📐 规律总结

主族金属（Na、Mg、Al）在化合物里只有一种价态，横看只有一条线；过渡元素 Cu、Fe 有两种以上价态，图上能"多站几个点"——价类图的难度，往往就藏在这条多出来的价态线上。

三个方向任选：换元素（Cu → Fe，画出 +2/+3 两条线）· 加点（在 +1 价加一个"[Cu(NH₃)₂]⁺"点）· 换设问（判断正误 → 写出 b→c 的离子方程式）

核心题3 · 铜氨配合物：从制溶液一路"镀"上铁钉
【2026·广东·高考真题·T17】
本课要做（文字题·只做第(1)(2)(3)问）（1）氨水的制备：需要选择的装置有______。
（2）制备铜氨溶液，以其为电解液在铁件表面镀铜，铁件连接直流电源______极。
（3）铜氨配合物的制备与表征：向 CuSO₄ 溶液中滴加氨水至过量，得到深蓝色溶液，加入乙醇，析出晶体，过滤，______，晾干得产物 Q。用 X 射线衍射仪测试 Q，观察到______，说明 Q 为晶体。
🧭 任务卡（同桌讨论 2 分钟）

① 实验室制 NH₃ 用哪一套装置？吸收多余 NH₃ 时，倒扣漏斗为什么能防倒吸？

② 铁件上镀铜：铁件和纯铜片各接电源哪一极？镀不上铜会是什么后果？

③ 从溶液里"捞"晶体，过滤之后还差哪一步？用什么手段证明它是晶体而不是玻璃体？

📚 解决本任务需要的知识

① 制 NH₃：NH₄Cl 固体＋Ca(OH)₂ 加热（固固加热型）

② NH₃ 极易溶于水 → 须用倒扣漏斗防倒吸

③ P₂O₅ 是酸性干燥剂，不能干燥碱性气体 NH₃

④ 电镀三要素：镀件作阴极、纯铜作阳极、电解液含 Cu²⁺；晶体用 X 射线衍射（明锐的衍射峰） 鉴别

🔑 全题"金钥匙"：电镀记"三定"——定极（镀件作阴极）、定线（接负极）、定液（含 Cu²⁺）；晶体＝原子有规则地周期排列＝明锐的衍射峰。
显示四段详解（讨论完再展开）
✅ 正确答案：(1) AB　(2) 负　(3) 洗涤；明锐的衍射峰

🧭 思路点拨

三小问各对应一项实验基本功：第(1)问考"制气＋尾气吸收"，第(2)问考"电镀电极判断"，第(3)问考"提纯与晶体表征"——把装置用途逐个说清楚，答案自然出来。

📌 逐项详解

(1) A 是固体＋固体加热制气装置（NH₄Cl 与 Ca(OH)₂），可制 NH₃；B 用倒扣漏斗把 NH₃ 通入水中，既能吸收又防倒吸，可制氨水；C 是盛 P₂O₅ 的干燥管，P₂O₅ 酸性，会与碱性 NH₃ 反应；D 是分液漏斗萃取装置，与制氨无关。故填 AB。
(2) 镀铜时铁件表面要析出铜，发生得电子的还原反应，作阴极，接直流电源负极（若接正极，铁自己溶解，镀不上铜）。
(3) 晶体表面附着可溶性杂质离子，需要洗涤除去，再晾干；X 射线衍射中观察到明锐的衍射峰，说明原子呈周期性有序排列，即 Q 为晶体。

⚠ 易错提醒

①"氨水过量"是生成 [Cu(NH₃)₄]²⁺ 的关键——氨水不足只能得到 Cu(OH)₂ 蓝色沉淀；②碱性气体 NH₃ 不能用酸性干燥剂（P₂O₅、浓 H₂SO₄），要用碱石灰；③晶体与非晶体的本质区别是原子排列是否周期性有序，XRD 只是鉴别手段。

📐 规律总结

这是"配合物应用"的一条完整链条：制铜氨溶液 → 电镀铜 → 制备晶体 → XRD 表征 → 与酸反应探究。2025 广东 T6 也考过同一情境（预处理铁钉＋铜氨溶液镀铜），2026 把它放大成 14 分压轴题——配合物是铜这一讲最热的生长点。

三个方向任选：换考点（问"为什么用乙醇析出晶体，而不是蒸发浓缩"）· 换电极（把铁件换成石墨，镀层还上得去吗）· 换设问（设计实验证明产物含 SO₄²⁻）

过关1 · 给铁钉镀铜：哪一步做不到
【2025·广东·高考真题·T6】

对铁钉进行预处理，并用铜氨溶液给铁钉镀铜。下列操作不能达到实验目的的是（　　）

A．除油污

B．除铁锈

C．制铜氨溶液

D．铁钉镀铜

显示四段详解
✅ 正确答案：D

🧭 思路点拨

"能否达到目的"三查：原理对不对、装置全不全、试剂选得对不对。逐个选项把"目的—原理—装置"对一遍。

📌 逐项详解

A：Na₂CO₃ 溶液显碱性，加热促进 CO₃²⁻ 水解使碱性增强，油污（酯类）在碱性条件下水解而被除去，能达到目的；

B：铁锈主要成分 Fe₂O₃，与稀盐酸反应（Fe₂O₃＋6H⁺＝2Fe³⁺＋3H₂O），能达到目的；

C：向 CuSO₄ 溶液中滴加足量氨水，先生成 Cu(OH)₂ 沉淀，氨水过量后继续溶解生成 [Cu(NH₃)₄]²⁺，得深蓝色铜氨溶液，能达到目的；

D：图中没有电源——镀铜属于电解，必须让 Cu 片接电源正极（阳极）、铁钉接电源负极（阴极），否则铁钉反而会被腐蚀，不能达到目的，选 D。

⚠ 易错提醒

①电镀必须通电——不能靠 Cu²⁺ 与 Fe 自发置换"镀"上去；②除油污是碱洗（水解），除铁锈是酸洗，顺序不能颠倒（先碱后酸）。

📐 规律总结

电镀与电解精炼同属"电解装置"，判装置先找电源：有电源→电解池（镀件作阴极）；无电源→只能是原电池，不能用于电镀。

过关2 · 铜丝"先变黑、再变红"说明了什么
【2025·广东·高考真题·T11】

利用如图装置进行实验：打开 K₁、K₂，一定时间后，a 中溶液变蓝；关闭 K₁，打开 K₃，点燃酒精灯加热数分钟后，滴入无水乙醇。下列说法错误的是（　　）

A．a 中现象体现了 I⁻ 的还原性

B．b 中 H₂O₂ 既作氧化剂也作还原剂

C．乙醇滴加过程中，c 中的铜丝由黑变红，说明乙醇被氧化

D．d 中有银镜反应发生，说明 c 中产物有乙酸

显示四段详解
✅ 正确答案：D

🧭 思路点拨

先把气路读通：b 制 O₂ → O₂ 使 a 中 I⁻ 变 I₂（溶液变蓝）→ O₂ 进 c 与灼热铜丝作用 → 产物进 d 检验。再看每个选项说的是不是这条链上的事实。

📌 逐项详解

A：a 中 2I⁻＋H₂O₂＋2H⁺＝I₂＋2H₂O，I⁻ 失电子被氧化，体现了 I⁻ 的还原性，正确；

B：H₂O₂ 中 O 为 −1 价，一部分升为 0（O₂）、一部分降为 −2（H₂O），既作氧化剂又作还原剂，正确；

C：铜丝先被 O₂ 氧化成黑色的 CuO，CuO 再把乙醇氧化为乙醛，自身被还原回红色的 Cu——"黑→红"正说明乙醇被氧化，正确；

D：银镜反应只能说明产物含醛基（即乙醛），不能说明有乙酸生成，错误，选 D。

⚠ 易错提醒

铜丝在乙醇催化氧化中扮演催化剂：先变黑（生成 CuO）、再变红（CuO 被还原），"黑红循环"是必考现象——不要以为变红是"铜被氧化"。

📐 规律总结

催化剂常见"两步走"：第一步被氧化、第二步被还原，循环之后自身复原——Cu 在这道题里是氧的"搬运工"。检验题通用原则：现象只能证到"有什么基团"，不能替产物命名。

过关3 · CuCl 凭什么"溶解"在盐酸里
【2025·广东·高考真题·T12】

CuCl 微溶于水，但在 Cl⁻ 浓度较高的溶液中因形成 [CuCl₂]⁻ 和 [CuCl₃]²⁻ 而溶解。将适量 CuCl 完全溶于盐酸，得到含 [CuCl₂]⁻ 和 [CuCl₃]²⁻ 的溶液，下列叙述正确的是（　　）

A．加水稀释，[CuCl₃]²⁻ 浓度一定下降

B．向溶液中加入少量 NaCl 固体，[CuCl₂]⁻ 浓度一定上升

C．H[CuCl₂] 的电离方程式为 H[CuCl₂]＝H⁺＋Cu⁺＋2Cl⁻

D．体系中浓度关系：c(Cu⁺)＋c(H⁺)＝c(Cl⁻)＋c([CuCl₂]⁻)＋c([CuCl₃]²⁻)＋c(OH⁻)

显示四段详解
✅ 正确答案：A

🧭 思路点拨

把"CuCl 溶解"翻译成配位平衡：CuCl(s)＋Cl⁻ ⇌ [CuCl₂]⁻，[CuCl₂]⁻＋Cl⁻ ⇌ [CuCl₃]²⁻。再用平衡移动（A、B）和"配离子不能拆"（C、D）逐项检验。

📌 逐项详解

A：加水稀释时体积增大占主导，各含铜微粒浓度都降低，[CuCl₃]²⁻ 浓度一定下降，正确；

B：加 NaCl 使两步平衡都正向移动，但 [CuCl₂]⁻ 一边生成、一边又被消耗，不一定上升，错误；

C：H[CuCl₂] 电离时只给出 H⁺ 和配离子 [CuCl₂]⁻——Cu⁺ 与 Cl⁻ 之间是配位键，不能拆开写成 Cu⁺＋2Cl⁻，错误；

D：[CuCl₃]²⁻ 带 2 个单位负电荷，电荷守恒中应写 2c([CuCl₃]²⁻)，选项漏了系数 2，错误。

⚠ 易错提醒

①配离子在方程式里整体书写，不能"拆"成中心离子和配体；②电荷守恒别漏离子电荷数（[CuCl₃]²⁻ 记 2 个单位）；③"一定"字眼要警惕——加同离子时生成与消耗同时发生。

📐 规律总结

这正是缺口 E04 的实战：Cu⁺ 在溶液中"站不住"，只有靠沉淀（CuCl）、配合物（[CuCl₂]⁻）、非水环境才能稳定存在。同源考法：2024 黑吉辽卷"Cu＋Cu²⁺＋2Cl⁻＝2CuCl"（归中生成 Cu⁺）。

过关4 · 铜丝与浓硫酸：方程式对不对
【2021·广东·高考真题·T15】

宏观辨识与微观探析是化学学科核心素养之一。下列物质性质实验对应的反应方程式书写正确的是（　　）

A．Na₂O₂ 放入水中：Na₂O₂＋H₂O＝2NaOH＋O₂↑

B．H₂O(g) 通过灼热铁粉：3H₂O＋2Fe＝Fe₂O₃＋3H₂

C．铜丝插入热的浓硫酸中：Cu＋H₂SO₄＝CuSO₄＋H₂↑

D．SO₂ 通入酸性 KMnO₄ 溶液中：5SO₂＋2H₂O＋2MnO₄⁻＝5SO₄²⁻＋4H⁺＋2Mn²⁺

显示四段详解
✅ 正确答案：D

🧭 思路点拨

方程式正误"四查"：查反应物、查产物、查条件、查守恒（元素＋电荷）——一条一条过，别凭印象。

📌 逐项详解

A：正确写法为 2Na₂O₂＋2H₂O＝4NaOH＋O₂↑，选项中氧元素不守恒，错误；

B：铁与水蒸气高温反应生成Fe₃O₄，不是 Fe₂O₃，错误；

C：铜与热的浓硫酸生成 SO₂ 不是 H₂，且方程式需标 Δ、并写 2H₂SO₄，错误；

D：SO₂ 被 MnO₄⁻ 氧化为 SO₄²⁻、Mn 由 +7 降为 +2，原子与电荷均守恒，正确。

⚠ 易错提醒

①浓硫酸与铜不放出 H₂（放 SO₂）——这是本讲最高频错点；②铁与水蒸气、铁与稀酸产物不同（Fe₃O₄ / Fe²⁺），要分清。

📐 规律总结

把"铜丝插酸"三个方程式当必背清单背到条件、配平、气体产物都不错：浓 H₂SO₄(Δ)→SO₂、浓 HNO₃→NO₂、稀 HNO₃→NO。
