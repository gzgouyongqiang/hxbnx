第6讲 · 物质的量浓度及溶液配制 · 缺口真题训练

联动缺口：配制五步规范 · c=n/V 双因子误差分析 · 滴定仪器选型　｜　全部选自高考真题
一缺口速览2分钟
  • 物质的量浓度定义 c = n / V：V 是"溶液体积"非溶剂体积；离子浓度 c(离子) = c(溶质) × 角标，与体积无关。含氯 ≠ 含 Cl⁻（如 NaClO 中氯为 ClO⁻）。
  • 溶质判断规则：与水反应按生成物算：Na/Na₂O/Na₂O₂ → NaOH，SO₂/SO₃ → H₂SO₃/H₂SO₄；结晶水合物按无水物算（CuSO₄·5H₂O → CuSO₄）；NH₃ 按 NH₃ 计。
  • 浓度与质量分数换算：c = 1000ρw / M（ρ 单位 g·cm⁻³）。浓溶液稀释三步：c(浓)=1000ρw/M → 按容量瓶规格定 V₂ → c₁V₁ = c₂V₂ 求量取体积。
  • 稀释守恒与电荷守恒：稀释：c₁V₁ = c₂V₂（溶质物质的量守恒）；混合体积 ≠ 加和。电荷守恒：阳离子浓度×电荷数之和 = 阴离子浓度×电荷数之和（求某离子捷径）。
  • 配制七步 + 误差分析：计算→称量→溶解→冷却→转移→洗涤→定容→摇匀。误差看 n、V：俯视偏高、仰视偏低、未洗涤偏低、未冷却偏高、容量瓶未干燥无影响。

核心题1 · 测浓硫酸含量：一条流程线"顺藤摸瓜"找仪器〔2021 广东 T7〕
【2021·广东卷 T7】
原题测定浓硫酸试剂中 H₂SO₄ 含量的主要操作包括：①量取一定量的浓硫酸，稀释；②转移定容得待测液；③移取 20.00 mL 待测液，用 0.1000 mol·L⁻¹ 的 NaOH 溶液滴定。上述操作中，不需要用到的仪器为（　　）
（原题选项为仪器示意图）
A量筒（或移液管）
B分液漏斗
C碱式滴定管
D容量瓶
🧭 任务卡（同桌讨论 3 分钟）

① 操作①量取浓硫酸——用量筒还是移液管？能不能用碱式滴定管量？

② 稀释浓硫酸"酸入水"用什么仪器？玻璃棒前后干两件什么活？

③ 定容必须用什么仪器？它的"一个刻度线"意味着什么？

④ 滴定用酸式还是碱式滴定管？为什么？

📚 解决本任务需要的知识

① 量筒（或移液管）量取；碱式滴定管不能量浓硫酸（腐蚀橡胶管）。

② 烧杯稀释＋玻璃棒搅拌散热；转移时玻璃棒引流。

③ 容量瓶是唯一"定容"仪器（一条刻度线）＋胶头滴管补加。

④ 滴 NaOH 用碱式滴定管（碱液腐蚀玻璃活塞，酸式管会粘死）。全程不出现分液漏斗。

🔑 仪器选择题万能套路：把操作拆成"量取 → 稀释 → 转移 → 定容 → 移取 → 滴定"六步，每步对应仪器列清单——分液漏斗只在"萃取分液"出现，配制与滴定全程用不到它。
显示四段详解（讨论完再展开）
✅ 答案：B（分液漏斗）

🧭 思路点拨

按流程"顺藤摸瓜"列仪器：①量取浓硫酸→量筒/移液管；②稀释→烧杯、玻璃棒；转移定容→容量瓶、胶头滴管；③滴定→碱式滴定管、锥形瓶。逐项对照，找出全程用不到的。

📌 逐项详解

A：√ 用到量取浓硫酸用（酸式）移液管或量筒。

B：分液漏斗用于分离互不相溶的液体（分液），本实验是"配制 + 滴定"，全程无分液操作——选 B。

C：√ 用到NaOH 是强碱，用碱式滴定管盛放滴定。

D：√ 用到转移定容得待测液需容量瓶。

⚠ 易错提醒

⚠ ①"分液漏斗" vs "漏斗"——过滤用漏斗，分液才用分液漏斗，本实验两者都不需要；②NaOH 滴定盛在碱式滴定管（橡胶管），不能装在酸式滴定管（磨口玻璃塞会被碱腐蚀）；③量取浓硫酸用移液管/量筒，不是用托盘天平（液体用量体积）。

📐 规律总结

✅ 仪器选择题按流程走：量取（量筒/移液管）→ 稀释（烧杯+玻璃棒）→ 定容（容量瓶+胶头滴管）→ 滴定（滴定管+锥形瓶）。配制 + 滴定的组合题，分液漏斗、温度计、坩埚几乎必是"用不到"的干扰项。

三个方向任选：换情境（配 100 mL 1.0 mol·L⁻¹ Na₂CO₃ 标准液）· 加干扰（"容量瓶用待测液润洗"对不对）· 改设问（"哪些步骤必须用玻璃棒"）

核心题2 · 四幅操作图挑错：天平、定容、摇匀、滴定〔2026 广东开学考〕
【2026·广东开学考（讲义课时精练 T3）】
原题下列实验操作规范的是（　　）
（原题为四幅操作示意图）
A在托盘天平上直接放称量纸称量 NaOH 固体
B向容量瓶中定容时，眼睛俯视刻度线加水
C容量瓶定容后倒置摇匀
D用酸式滴定管盛装 NaOH 标准液滴定醋酸
🧭 任务卡（同桌讨论 4 分钟）

① NaOH 固体垫纸称量行不行？为什么？

② 定容时俯视刻度线——实际液面偏高还是偏低？浓度偏高还是偏低？

③ 定容倒置摇匀后液面低于刻度线——要不要再加水？

④ 用 NaOH 标准液滴定醋酸——选酸式还是碱式滴定管？

📚 解决本任务需要的知识

① NaOH 潮解＋腐蚀：垫纸会粘且吸水称不准——用小烧杯（左物右码）。

② 俯视定容：实际液面低于刻度 → V 偏小 → c 偏高（c=n/V 双因子）。

③ 倒置摇匀后液面低是正常现象（部分溶液挂壁回流中），不能再加水。

④ 碱液用碱式滴定管；口诀"碱碱酸酸"——碱液碱式管、酸液酸式管。

🔑 配制五步"查错表"：计算 → 称量（腐蚀性用烧杯）→ 溶解冷却 → 转移洗涤 → 定容摇匀（平视！倒置后不再加水）。误差分析认准 c=n/V 双因子：n 怎么变、V 怎么变，直接定 c 的方向。
显示四段详解（讨论完再展开）
✅ 正确答案：C

🧭 思路点拨

逐图审查"操作对象、仪器匹配、视线、指示剂"：称量（腐蚀性物质用烧杯）、定容（胶头滴管＋平视）、摇匀（倒置振荡）、滴定（酸式/碱式管选型＋指示剂）。

📌 逐项详解

A：×NaOH 强腐蚀性＋吸水性，不能放称量纸上，应置于小烧杯中称量。

B：×定容需用胶头滴管逐滴加水至刻度，且眼睛平视刻度线（俯视导致偏高）。

C：√定容后应将容量瓶倒置摇匀，使溶液混合均匀。

D：×NaOH 是强碱，应装碱式滴定管；滴定醋酸（终点 CH₃COONa 呈碱性）用酚酞指示剂。

⚠ 易错提醒

⚠ ①NaOH 称量必须用小烧杯（腐蚀性＋吸水性）；②定容两要素——胶头滴管＋平视，缺一不可；③滴定管选型——酸式管装酸/氧化性液，碱式管装碱液；NaOH 滴定醋酸用酚酞，不用甲基橙。

📐 规律总结

✅ 实验操作图题"四查"：①称量（腐蚀性物质用烧杯）②定容（胶头滴管＋平视）③摇匀（倒置振荡）④滴定（管选型＋指示剂变色范围）。一个图对应一个规范，逐图排除。

三个方向任选：换操作（量筒读数俯视的误差）· 加图（移液管放液后残留 1 滴要不要吹出）· 改设问（仰视定容，浓度偏高还是偏低）

过关1 · 仪器清单缺谁——容量瓶与分液漏斗辨用途
【2023·全国甲卷 T9】

实验室将粗盐提纯并配制 0.1000 mol·L⁻¹ 的 NaCl 溶液。下列仪器中，本实验必须用到的有（　　）
①天平　②温度计　③坩埚　④分液漏斗　⑤容量瓶　⑥烧杯　⑦滴定管　⑧酒精灯

A①②④⑥
B③⑤⑦⑧
C①③⑤⑥
D①⑤⑥⑧
显示四段详解
✅ 答案：D（①⑤⑥⑧）

🧭 思路点拨

把"粗盐提纯"与"配制 NaCl 溶液"两个流程的仪器分别列出，再取并集。粗盐提纯：溶解（烧杯、玻璃棒）→过滤（漏斗）→蒸发结晶（蒸发皿、酒精灯）；配液：称量（天平）→溶解（烧杯）→移液定容（容量瓶、胶头滴管）。

📌 逐项详解

①✓天平——配制称量 NaCl 用。 ⑤✓容量瓶——配制定容用。 ⑥✓烧杯——提纯溶解、配液溶解均用。 ⑧✓酒精灯——提纯蒸发结晶用。 ②③④⑦×温度计（测蒸汽温度）、坩埚（灼烧固体，蒸发结晶用蒸发皿）、分液漏斗（分液）、滴定管（滴定）——均不必要。

⚠ 易错提醒

⚠ ①蒸发结晶用蒸发皿，灼烧固体才用坩埚——③坩埚是高频干扰项；②过滤用漏斗，分液才用分液漏斗——④别混；③配液不需要温度计和滴定管，二者都是"其他实验"的仪器。

📐 规律总结

✅ "仪器清单"题按流程顺藤摸瓜：提纯流程＝溶解→过滤→蒸发（烧杯、玻璃棒、漏斗、蒸发皿、酒精灯）；配液流程＝计算→称量→溶解→移液→洗涤→定容→摇匀（天平、烧杯、玻璃棒、容量瓶、胶头滴管）。两流程并集即答案。

过关2 · 操作目的题——转移前为什么必须"冷却"
【2024·全国甲卷 T(4)】

下图为"溶液配制"的部分过程，操作 a 应重复 3 次，目的是 ____，定容后还需要的操作为 ____。

显示四段详解
✅ 答案：将烧杯和玻璃棒上残留的溶质全部转移至容量瓶（避免溶质损失）；摇匀（盖好瓶塞，上下颠倒摇匀）

🧭 思路点拨

操作 a 是"洗涤"——用少量蒸馏水洗涤烧杯和玻璃棒 2~3 次，洗涤液全部转入容量瓶。其目的从"溶质是否损失"角度答；定容后的操作是"摇匀"使浓度均匀。

📌 逐项详解

第一空：洗涤并转移的目的是保证溶质全部进入容量瓶——若烧杯、玻璃棒上残留溶质，则 n(溶质) 偏小，浓度偏低。
第二空：定容后需盖好瓶塞、上下颠倒摇匀，使溶液混合均匀，浓度上下一致。

⚠ 易错提醒

⚠ ①洗涤液必须转入容量瓶，漏转 = 溶质损失 = 偏低；②摇匀后液面下降是挂壁所致，不能再加水，否则稀释、浓度偏低；③答"目的"要落到"避免溶质损失/保证全部转移"，不能只写"洗涤"。

📐 规律总结

✅ 配制流程中"洗涤→转移"是保证溶质不损失的关键步骤，"摇匀"是保证浓度均匀的收尾步骤。广东卷实验题常以填空形式考"某操作的目的/作用"，答案务必落到 c = n/V 的 n 或 V 上。

过关3 · 离子浓度比较——c=n/V 双因子拆解
【讲义课时精练 T1】

下列溶液中 c(Cl⁻) 最大的是（　　）

A200 mL 2 mol·L⁻¹ MgCl₂ 溶液
B100 mL 2.5 mol·L⁻¹ NaCl 溶液
C100 mL 2 mol·L⁻¹ NaClO 溶液
D300 mL 1 mol·L⁻¹ AlCl₃ 溶液
显示四段详解
✅ 正确答案：A

🧭 思路点拨

离子浓度只由"溶质浓度 × 化学式中该离子个数"决定，与溶液体积无关！逐一算出 c(Cl⁻) 比较大小即可。

📌 逐项详解

A：√MgCl₂：c(Cl⁻) = 2 × 2 = 4 mol·L⁻¹，最大。

B：×NaCl：c(Cl⁻) = 2.5 × 1 = 2.5 mol·L⁻¹。

C：×NaClO 中氯以 ClO⁻ 形式存在，没有 Cl⁻，c(Cl⁻) = 0——陷阱项。

D：×AlCl₃：c(Cl⁻) = 1 × 3 = 3 mol·L⁻¹。

⚠ 易错提醒

⚠ ①浓度与体积无关——200 mL 与 2 L 的 2 mol·L⁻¹ MgCl₂ 中 c(Cl⁻) 都是 4 mol·L⁻¹，体积只影响物质的量；②NaClO 中的 Cl 是 +1 价（ClO⁻），不是 Cl⁻——"含氯"≠"含 Cl⁻"。

📐 规律总结

✅ 离子浓度公式：c(离子) = c(溶质) × 化学式中离子角标。比较 c(Cl⁻) 只看 c(溶质)×角标，与体积、离子总数无关。此考点广东卷高频，10 秒一题。

过关4 · 误差分析——俯视仰视配对定浓度
【讲义课时精练 T4】

配制一定物质的量浓度的溶液时，下列操作会使所配溶液浓度偏高的是（　　）

A称量时左盘高、右盘低（药品放在左盘）
B定容时俯视刻度线
C容量瓶洗净后未干燥
D摇匀后液面下降，再加水至刻度线
显示四段详解
✅ 正确答案：B

🧭 思路点拨

误差分析统一用 c = n/V 双因子法：使"溶质 n 偏大"或"体积 V 偏小"→偏高；反之偏低；与 n、V 无关→无影响。

📌 逐项详解

A：×左盘高、右盘低（左物右码）：左盘轻→药品质量偏小→n 偏小→偏低。

B：√定容俯视：视线偏低→加水不足→V 偏小→偏高。

C：×容量瓶未干燥：瓶壁残留水不影响最终定容体积→n、V 均不变→无影响。

D：×摇匀后补水：正常挂壁导致液面下降，补水→V 偏大→偏低。

⚠ 易错提醒

⚠ ①摇匀后液面下降不能补水——刻度线按定容时确定，下降是挂壁所致，补水即稀释；②容量瓶不干燥无影响（定容时会补足体积）；③视线口诀：容量瓶俯视→体积偏小→偏高，仰视→偏低（与量筒方向相反）。

📐 规律总结

✅ 误差分析"十字诀"：看 n（溶质）与 V（体积）谁变了。高频结论：称量偏小/溅出→偏低；洗涤液未转移→偏低；定容俯视→偏高、仰视→偏低；摇匀后补水→偏低；容量瓶未干燥→无影响。

过关5 · 浓硫酸稀释选容量瓶——规格与计算一起想
【讲义课时精练 T6】

配制 200 mL 1.84 mol·L⁻¹ 的稀硫酸（浓硫酸密度 1.84 g·cm⁻³，质量分数 98%），下列说法正确的是（　　）

A稀释时可将水缓慢倒入浓硫酸中
B应选用 200 mL 容量瓶，用托盘天平称量浓硫酸
C应量取 20.0 mL 浓硫酸
D量取浓硫酸时仰视、定容时俯视，均使浓度偏高
显示四段详解
✅ 正确答案：D

🧭 思路点拨

①稀释操作：酸入水；②无 200 mL 容量瓶，配制 200 mL 按 250 mL 规格计；③由 c=1000ρw/M 求浓硫酸浓度，再用稀释定律 n 守恒求量取体积；④仰视/俯视分别作用于"量取"和"定容"。

📌 逐项详解

A：×稀释浓硫酸必须"酸入水"（将浓硫酸缓慢注入水中并搅拌），"水入酸"危险。

B：×无 200 mL 容量瓶，应选 250 mL；量取浓硫酸用量筒（液体），不用托盘天平。

C：×c(浓) = 1000×1.84×98%÷98 = 18.4 mol·L⁻¹。按 250 mL：n = 1.84×0.25 = 0.46 mol，V(浓) = 0.46÷18.4 = 0.025 L = 25.0 mL（非 20.0 mL）。

D：√量取仰视→实际量取偏多→n 偏大→偏高；定容俯视→V 偏小→偏高，两者都偏高。

⚠ 易错提醒

⚠ ①容量瓶规格只能选恰好 ≥ 目标体积的常用规格（100/250/500/1000 mL）——"200 mL 用 200 mL 容量瓶"是错误认知；②稀释定律 V 用 250 mL（规格）而非 200 mL，20.0 mL 是拿 200 算的错解；③量筒俯仰视与容量瓶相反：量筒仰视读数偏小（实际多）。

📐 规律总结

✅ 浓溶液稀释三步：①c(浓)=1000ρw/M 求浓度 → ②按容量瓶规格定 V₂（非目标体积）→ ③c₁V₁=c₂V₂ 求量取体积。浓硫酸稀释永远"酸入水"。

过关6 · 稀释＋电荷守恒——两步计算一条链
【讲义课时精练 T7】

某溶液（0.2 L）含 K⁺、SO₄²⁻、Na⁺、Mg²⁺、Cl⁻。已知图甲为各离子浓度条形图（K⁺ 2 mol·L⁻¹、SO₄²⁻ 1 mol·L⁻¹、Na⁺ 1 mol·L⁻¹），图乙为该溶液稀释过程中 c(Mg²⁺) 随总体积的变化曲线（稀释后总体积 1.0 L 时 c(Mg²⁺) = 0.2 mol·L⁻¹）。回答：
(1) 原溶液中 c(Mg²⁺) = ____ mol·L⁻¹；
(2) 原溶液中 c(Cl⁻) = ____ mol·L⁻¹。

显示四段详解
✅ 答案：(1) 1 (2) 7

🧭 思路点拨

(1) 由图乙稀释曲线 + 稀释定律求 c(Mg²⁺)；(2) 由图甲读出各离子浓度，用电荷守恒求 c(Cl⁻)——这是求某未知离子浓度的唯一捷径。

📌 逐项详解

(1) 稀释定律 n 守恒：c(原)·V(原) = c(稀)·V(稀)，即 c(Mg²⁺)×0.2 = 0.2×1.0，c(Mg²⁺) = 1 mol·L⁻¹。
(2) 电荷守恒：2c(K⁺) + 2c(Mg²⁺) + c(Na⁺) = 2c(SO₄²⁻) + c(Cl⁻)，代入 2×2 + 2×1 + 1 = 2×1 + c(Cl⁻)，得 c(Cl⁻) = 7 mol·L⁻¹。

⚠ 易错提醒

⚠ ①电荷守恒中离子浓度必须乘电荷数（Mg²⁺ 乘 2、SO₄²⁻ 乘 2），漏乘是最大失分点；②稀释定律的 V 用稀释前后总体积（0.2 L 与 1.0 L）；③读数带单位（mol·L⁻¹），K⁺ 是 2 mol·L⁻¹ 不是 2 mol。

📐 规律总结

✅ 电荷守恒式：阳离子浓度×电荷数之和 = 阴离子浓度×电荷数之和。已知大部分离子浓度求某一离子时，电荷守恒是唯一捷径；稀释曲线题"找稀释后某点回代稀释定律"。
