一缺口速览2分钟
  • 信息型氧化还原方程式书写（四步法）：陌生情境（流程/实验/机理图）中先"找物质"再配平：找物质 → 判升降 → 电子守恒定系数 → 补电荷配 H₂O。广东卷化工大题几乎年年必考。
  • 缺项配平（补 H⁺/OH⁻/H₂O 原则）：口诀"酸补 H⁺、碱补 OH⁻、H₂O 两边补"：先看介质，再算电荷差补离子，最后原子守恒补 H₂O。课本不教但高考必考。
  • 有机物参与的氧化还原配平：H 为 +1、O 为 -2，由分子式求碳平均化合价，再按升降法配平；配体（如 CO）整体搬运不变价。碳原子数勿漏乘。
  • 多步/多元素链式电子转移（整体法）：同一物质中多种元素同时变价（如 Fe(CrO₂)₂ 中 Fe、Cr 共升 7 价）用"整体法"求每分子总升降，再取最小公倍数定系数。
  • 歧化/归中反应的深度配平：歧化：中间价→高+低价，从生成物逆向配平；归中：高+低价→中间价，从反应物正向配平。自身氧化还原（NH₄NO₃、KClO₃）是归中特例。
  • 氧化还原电子转移数的综合判断：歧化取单侧、变价元素按用量定价态、部分氧化、竞争分步求和。先写方程式 → 标化合价 → 定产物价态 → 算单侧电子。

核心题1 · 从金精矿到真金：[AuCl₄]⁻ 的四步法缺项配平〔2026 广东 T18(5)〕
【2026·广东卷 T18(5)】
原题金（Au）是一种战略性金属。从某金精矿（含金、银、Sb₂S₃、FeS₂、SiO₂ 和 MgO 等）中提取金并综合利用部分物质的一种工艺如下（流程略）。(5)"沉金"通过 NaOH 的调控使反应在弱酸性条件下进行，生成 Au 的离子方程式为
2[AuCl₄]⁻ + ____ HSO₃⁻ + ____ = 2Au↓ + ____ + 8Cl⁻ + ____ H⁺
🧭 任务卡（同桌讨论 4 分钟）

① 谁升价谁降价？标出 [AuCl₄]⁻ 中 Au 的价态与 HSO₃⁻ 中 S 的价态。

② 电子守恒定系数：Au 从 +3→0 得 3e⁻、S 从 +4→+6 失 2e⁻，最小公倍数是多少？

③ 题干明示"弱酸性"——缺的补 H⁺ 还是 OH⁻？

④ 电荷守恒验收：左边 −2−3，右边 3×(−2)+8×(−1)+3×(+1)——差谁补谁？

📚 解决本任务需要的知识

① 四步法：找物质 → 判升降 → 电子守恒 → 缺啥补啥（酸性补 H⁺，碱性补 OH⁻，H/O 两边补 H₂O）。

② HSO₃⁻ 中 S 是 +4 价（亚硫酸氢根）——标错成 +6 则系数全错。

③ [AuCl₄]⁻ 的 8 个 Cl⁻ 全部进产物，漏写 Cl⁻ 电荷必不守恒。

④ 介质是题干明给的"路标"：弱酸性补 H⁺，绝不能补 OH⁻。

🔑 缺项配平"四步法"：找物质 → 判升降 → 电子守恒 → 缺啥补啥。介质条件决定补什么——弱酸性补 H⁺、弱碱性补 OH⁻、H/O 两边补 H₂O。四步走完再用电荷守恒回查一遍，广东大题的 2 分就是这么稳拿的。
显示四段详解（讨论完再展开）
✅ 答案：3 · 3H₂O · 3SO₄²⁻ · 9

🧭 思路点拨

四步法：①找物质——[AuCl₄]⁻ 中 Au 降价，HSO₃⁻ 中 S 升价；②判升降——Au 由 +3→0，2 个 Au 共得 6e⁻；HSO₃⁻ 中 S 由 +4→+6，每个失 2e⁻；③电子守恒——6 ÷ 2 = 3，HSO₃⁻ 系数为 3；④补电荷配水——左侧电荷 -2-3 = -5，右侧已定 3SO₄²⁻ + 8Cl⁻ 共 -14，需补 9 个 H⁺（+9）使两侧电荷均为 -5；再按 H、O 守恒补 3H₂O。

📌 逐项详解

配平结果：2[AuCl₄]⁻ + 3HSO₃⁻ + 3H₂O = 2Au↓ + 3SO₄²⁻ + 8Cl⁻ + 9H⁺
守恒验证——Au：2=2；S：3=3；Cl：8=8；O：3×3+3=12 = 3×4=12；H：3×2+3=9 = 9；电荷：-2-3=-5 = -6-8+9=-5 ✓

⚠ 易错提醒

⚠ ①介质判断——题干明示弱酸性，缺 H 补 H⁺，绝不能补 OH⁻；②HSO₃⁻ 中 S 是 +4 价（亚硫酸氢根），不是 +6，标价错则系数全错；③[AuCl₄]⁻ 中的 8 个 Cl⁻ 全部进入产物，漏写 Cl⁻ 会导致电荷不守恒；④Au 是 +3 价（Au(Ⅲ)），不是 +1。

📐 规律总结

✅ 缺项配平四步链：标价 → 电子守恒定系数 → 电荷守恒补离子 → 原子守恒补 H₂O。2026 广东卷该问是"半填空"形式（系数 + 缺项都考），正是 G18 四步法 + G19 补项原则的合体——广东卷化工大题"陌生离子方程式书写"近 6 年考 6 次，此模板必须烂熟。

三个方向任选：改介质（"弱碱性"条件下怎么补）· 换还原剂（把 HSO₃⁻ 换成 ClO⁻）· 改设问（"转移 6 mol 电子时消耗 HSO₃⁻ 多少 mol"）

核心题2 · 氧化沉钴：为什么 Mn²⁺ 也要写进方程式〔2024 新课标 T27(3)〕
【2024·新课标卷 T27(3)】
原题钴及其化合物在制造合金、磁性材料、催化剂及陶瓷釉等方面有着广泛应用。一种从湿法炼锌产生的废渣（主要含 Co、Zn、Pb、Fe 的单质或氧化物）中富集回收得到含锰高钴成品的工艺如下（流程略，调 pH=4 后加入 KMnO₄ 氧化沉淀）。"氧化沉钴"中氧化还原反应的离子方程式为 ____、____。（写出 Co²⁺ 被氧化为 Co(OH)₃ 沉淀的反应；体系中 Mn²⁺ 也会被氧化为 MnO₂ 沉淀）
🧭 任务卡（同桌讨论 4 分钟）

① Co²⁺ 与 MnO₄⁻ 各自的价态变化？产物为什么是 Co(OH)₃ 而不是 Co³⁺？

② 电荷守恒要补什么离子？pH=4 的弱酸环境提示了什么？

③ 题目问"氧化还原反应"（要写两个）——第二个反应里谁氧化谁？

④ 用四步法把两个方程式各走一遍，互相验收。

📚 解决本任务需要的知识

① pH=4 弱酸性下 Co³⁺ 强烈水解沉淀——产物写 Co(OH)₃↓，不能写 Co³⁺。

② MnO₄⁻ 的还原产物是 MnO₂（不是 Mn²⁺）。

③ Mn²⁺ 也能被 MnO₄⁻ 氧化成 MnO₂——"双反应"漏一个是常见丢分。

④ 参考答案：3Co²⁺+MnO₄⁻+7H₂O=3Co(OH)₃↓+MnO₂↓+5H⁺；3Mn²⁺+2MnO₄⁻+2H₂O=5MnO₂↓+4H⁺。

🔑 流程题缺项配平"三看"：看介质（定补什么离子）、看产物形态（pH=4 时高价金属写氢氧化物）、看双反应（MnO₄⁻ 既氧化 Co²⁺ 也氧化 Mn²⁺，漏一个丢一半分）。
显示四段详解（讨论完再展开）
✅ 答案：3Co²⁺+MnO₄⁻+7H₂O=3Co(OH)₃↓+MnO₂↓+5H⁺；3Mn²⁺+2MnO₄⁻+2H₂O=5MnO₂↓+4H⁺

🧭 思路点拨

①找物质：Co²⁺（+2）被 MnO₄⁻（+7）氧化，产物分别是 Co(OH)₃ 沉淀和 MnO₂ 沉淀；②判升降：Co +2→+3 失 1e⁻，Mn +7→+4 得 3e⁻ → Co²⁺ : MnO₄⁻ = 3 : 1；③电荷守恒补离子：左侧 3×(+2)+(-1)=+5，右侧 0，补 5H⁺；④原子守恒补 H₂O：左侧 H 不足，3Co(OH)₃ 需 7H₂O。第二个反应：Mn²⁺ +2→+4 失 2e⁻，MnO₄⁻ +7→+4 得 3e⁻ → 3Mn²⁺ : 2MnO₄⁻，同理配平。

📌 逐项详解

反应一：3Co²⁺ + MnO₄⁻ + 7H₂O = 3Co(OH)₃↓ + MnO₂↓ + 5H⁺
反应二：3Mn²⁺ + 2MnO₄⁻ + 2H₂O = 5MnO₂↓ + 4H⁺
守恒验证（反应一）：Co 3=3、Mn 1=1、O 7+4=11 = 9+2=11、H 14=9+5=14、电荷 +6-1=+5 = +5 ✓

⚠ 易错提醒

⚠ ①两个反应都要写——Co²⁺ 和 Mn²⁺ 都能被 MnO₄⁻ 氧化，漏第二个是常见丢分；②产物是 Co(OH)₃沉淀而非 Co³⁺ 离子（pH=4 时 Co³⁺ 强烈水解沉淀），Fe³⁺ 同理；③MnO₄⁻ 被还原为 MnO₂（+4）而非 Mn²⁺（+2），由 pH=4 环境决定——酸性弱则 Mn 降到 +4 即沉淀。

📐 规律总结

✅ 流程题"氧化沉淀"模型：加氧化剂（MnO₄⁻/H₂O₂/O₂）将低价金属离子氧化为高价氢氧化物或氧化物沉淀，本质 = 缺项配平 + 沉淀反应复合。产物价态由溶液酸碱性（pH）决定，先看介质再定产物，这是 G19"介质决定一切"的核心思想。

三个方向任选：改条件（强酸性时 MnO₄⁻ 的还原产物变成什么）· 换沉淀剂（调 pH 改用 NaOH 过量）· 改设问（"氧化 1 mol Co²⁺ 转移电子数"）

过关1 · 整体法配平——两种物质"打包"算升降
【2021·河北卷 T15(5)】

配平下列化学方程式（铬铁矿提铬工艺）：
____Fe(CrO₂)₂ + ____O₂ + ____NaHCO₃ = ____Na₂CrO₄ + ____Fe₂O₃ + ____CO₂ + ____H₂O

显示四段详解
✅ 答案：4 · 7 · 16 · 8 · 2 · 16 · 8

🧭 思路点拨

整体法：Fe(CrO₂)₂ 中 Fe 和 Cr 同时变价——Fe +2→+3 升 1 价；2 个 Cr +3→+6 各升 3 价，共升 6 价；每分子 Fe(CrO₂)₂ 总升 7 价。O₂ 中 2 个 O 0→-2，每分子 O₂ 降 4 价。7 与 4 的最小公倍数为 28 → Fe(CrO₂)₂ 系数 4、O₂ 系数 7。再按 Na、Fe、Cr、C、H 原子守恒依次配 Na₂CrO₄（8）、Fe₂O₃（2）、CO₂（16）、H₂O（8）、NaHCO₃（16）。

📌 逐项详解

4Fe(CrO₂)₂ + 7O₂ + 16NaHCO₃ = 8Na₂CrO₄ + 2Fe₂O₃ + 16CO₂ + 8H₂O
守恒验证——Fe 4=4、Cr 8=8、Na 16=16、C 16=16、H 16=16、O：8+14+48=70 = 32+6+32+8=78？
重新核对：左侧 O = 4×4(Fe(CrO₂)₂ 中 8 个 O)=16 + 7×2=14 + 16×3=48 → 78；右侧 O = 8×4(Na₂CrO₄)=32 + 2×3=6 + 16×2=32 + 8×1=8 → 78 ✓ 电子：Fe(CrO₂)₂ 升 7×4=28e⁻，O₂ 降 4×7=28e⁻ ✓

⚠ 易错提醒

⚠ ①Fe、Cr 双变价必须整体算——只算 Cr 忽略 Fe 会得出错误系数；②Cr 是 +3（CrO₂⁻ 中）不是 +6，先标价；③NaHCO₃ 是"不变价配角"：提供 Na⁺ 生成 Na₂CrO₄、提供 C/H/O 生成 CO₂ 和 H₂O，最后用原子守恒配它；④Cr 守恒提示：产物 Na₂CrO₄ 系数 = Fe(CrO₂)₂ 系数 × 2。

📐 规律总结

✅ G21 整体法口诀："一物多元素变价，先算分子总升降"。Fe(CrO₂)₂（升 7）、FeS₂（Fe 升 1 + 2S 各升 5 = 升 11 被 O₂ 氧化时）、NH₄NO₃ 等含多变价元素的物质，一律整体求总升降再取最小公倍数，是流程题焙烧/煅烧方程式书写的万能起点。

过关2 · 配合物配平——[Cu(NH₃)₄]²⁺ 别拆错
【2025·河北卷 T16(6)】

铬盐产品广泛应用于化工、医药、印染等领域。通过闭环生产工艺将铬铁矿转化为重铬酸钾同时回收利用钾资源。已知：铬铁矿主要成分是 Fe(CrO₂)₂、Mg(CrO₂)₂、Al₂O₃、SiO₂。还原、分离工序中，Fe(CO)₅ 作还原剂，将滤液中的 K₂CrO₄ 还原为 Cr(OH)₃，自身转化为 Fe(OH)₃。补全该化学方程式：
Fe(CO)₅ + ____ + ____ = Cr(OH)₃↓ + ____ + ____ + ____CO

显示四段详解
✅ 答案：K₂CrO₄ · 4H₂O · Fe(OH)₃↓ · 2KOH · 5

🧭 思路点拨

①找物质：还原剂 Fe(CO)₅ 中 Fe 为 0 价（羰基配合物）→ Fe(OH)₃ 中 +3 价，失 3e⁻；氧化剂 K₂CrO₄ 中 Cr +6→Cr(OH)₃ 中 +3，得 3e⁻ → 主系数 1 : 1；②CO 是配体，5 个 CO 整体放出（C、O 价态不变），产物写 5CO；③原子守恒：Fe、Cr 各 1，K 有 2 个 → 生成 2KOH；O、H 配平 → 需 4H₂O。

📌 逐项详解

Fe(CO)₅ + K₂CrO₄ + 4H₂O = Cr(OH)₃↓ + Fe(OH)₃↓ + 2KOH + 5CO
守恒验证——Fe 1=1、Cr 1=1、K 2=2、C 5=5、O 5+4+4=13 = 3+3+2+5=13、H 8=3+3+2=8、电荷 0=0 ✓ 电子：Fe 失 3e⁻ = Cr 得 3e⁻ ✓

⚠ 易错提醒

⚠ ①Fe(CO)₅ 中 Fe 是 0 价——羰基配合物中 CO 配体电中性，Fe 不显 +2/+3，标价错则全盘皆错；②CO 是配体整体搬运，不参与氧化还原，但 5 个 CO 必须写全，漏一个 C/O 就不守恒；③K⁺ 去向：碱性环境以 KOH 留在溶液，不是 K₂CO₃；④产物是氢氧化物沉淀，注意 ↓ 符号。

📐 规律总结

✅ G20 配合物/有机物配平两步：先标中心原子价态（配体整体为 0）→ 电子守恒定主系数 → 配体原样搬运 → 原子守恒补 H₂O/H⁺/OH⁻。Fe(CO)₅、FeS₂、C₂O₄²⁻ 同类："中心原子变价 + 配体/整体搬运"，碳原子数、配体数勿漏乘。

过关3 · 过氧键——H₂O₂ 里 O 是 −1 价
【2023·辽宁卷 T16 改编】

pH=4 时，Mn²⁺ 被过一硫酸（H₂SO₅）氧化为 MnO₂，该反应的离子方程式为 ____（H₂SO₅ 的电离第一步完全，第二步微弱——溶液中以 HSO₅⁻ 存在）。

显示四段详解
✅ 答案：Mn²⁺ + HSO₅⁻ + H₂O = MnO₂↓ + SO₄²⁻ + 3H⁺

🧭 思路点拨

①找物质：Mn²⁺ +2→MnO₂ 中 +4，失 2e⁻；HSO₅⁻ 是过一硫酸根，含过氧键 -O-O-，2 个过氧 O 各由 -1 价降为 -2 价，共得 2e⁻（S 仍为 +6 不变价）；②电子守恒 1 : 1；③介质 pH=4 酸性 → 缺 H 补 H⁺；④原子守恒补 H₂O：左侧 HSO₅⁻ 1 个 H，产物 3H⁺ 需 3 个 H → 补 1 H₂O。

📌 逐项详解

Mn²⁺ + HSO₅⁻ + H₂O = MnO₂↓ + SO₄²⁻ + 3H⁺
守恒验证——Mn 1=1、S 1=1、O 5+1=6 = 2+4=6、H 1+2=3 = 3、电荷 +2-1=+1 = -2+3=+1 ✓ 电子：Mn 失 2e⁻ = 过氧 O 得 2e⁻ ✓

⚠ 易错提醒

⚠ ①H₂SO₅ 中 S 仍是 +6 价，氧化 Mn²⁺ 的是过氧键中的 O（-1→-2），标价时把 H₂SO₅ 全按 S+6/O-2 标会直接算不出电子守恒；②"电离第一步完全"决定反应粒子写 HSO₅⁻ 而非 H₂SO₅；③MnO₂ 是沉淀，别漏 ↓；④酸性介质补 H⁺，产物在右侧。

📐 规律总结

✅ 含过氧键氧化剂速记：H₂O₂、Na₂O₂、H₂SO₅、K₂S₂O₈ 中 O 均含 -1 价（过氧），变价对象是 O 不是中心元素。见到"过一硫酸/过硫酸/过氧化氢"先标过氧 O 的 -1 价，再算升降——这是广东卷流程题（氧化浸出用 S₂O₈²⁻、H₂O₂）的高频设坑点。

过关4 · 先定价态再配平——信息型方程式的价态陷阱
【2023·山东卷 T16(3) 改编】

一定条件下，CuCl₂、K 与 F₂ 反应生成 KCl 和化合物 K₂CuF₄，写出该反应的化学方程式。

显示四段详解
✅ 答案：4K + 2F₂ + CuCl₂ = K₂CuF₄ + 2KCl

🧭 思路点拨

①找物质：反应物 CuCl₂、K、F₂；生成物 KCl、K₂CuF₄；②判升降：K 0→+1 失 1e⁻；F 0→-1 得 1e⁻；Cu 在 CuCl₂ 与 K₂CuF₄ 中均为 +2，价态不变；③电子守恒：K 与 F 1 : 1；④原子守恒：K₂CuF₄ 含 4 个 F、K₂CuF₄ 与 KCl 共 4 个 K → F₂ 系数 2、K 系数 4，CuCl₂ 系数 1（2 个 Cl 进 2KCl）。

📌 逐项详解

4K + 2F₂ + CuCl₂ = K₂CuF₄ + 2KCl
守恒验证——K 4=2+2=4、F 4=4、Cu 1=1、Cl 2=2、电荷 0=0 ✓ 电子：K 失 4e⁻ = F 得 2×2=4e⁻ ✓

⚠ 易错提醒

⚠ ①K₂CuF₄ 中 Cu 仍是 +2（[CuF₄]²⁻ 配离子），别被"K₂CuF₄ 是新物质"迷惑而误判 Cu 变价——由化合价代数和：2K(+1) + Cu + 4F(-1) = 0 → Cu = +2；②K 既是还原剂又进产物 KCl，系数要两边同时满足；③F₂ 是强氧化剂，产物 F 全为 -1。

📐 规律总结

✅ 信息型四步法闭环：找物质 → 判升降（含"不变价"判定）→ 电子守恒定系数 → 原子守恒收尾。陌生化合物（K₂CuF₄）先算化合价代数和确定各元素价态，明确"谁变价、谁没变"，再动笔配平——G18 的核心是判断，不是计算。

过关5 · 自身氧化还原——歧化里"一人分饰两角"
【讲义课时精练 T4】

一定条件下，硝酸铵受热分解的化学方程式（未配平）为 NH₄NO₃ —→ HNO₃ + N₂↑ + H₂O，下列说法错误的是（　　）
A配平后 H₂O 的化学计量数为 6 BNH₄NO₃ 既是氧化剂又是还原剂 C该反应既是分解反应也是氧化还原反应 D氧化产物和还原产物的物质的量之比为 5∶3

显示四段详解
✅ 正确答案：A

🧭 思路点拨

先配平：5NH₄NO₃ = 2HNO₃ + 4N₂↑ + 9H₂O。NH₄NO₃ 中两个 N 价态不同——NH₄⁺ 中 N 为 -3 价（被氧化），NO₃⁻ 中 N 为 +5 价（被还原），自身氧化还原。5 个 NH₄⁺ 失 5×3=15e⁻，需 3 个 NO₃⁻ 得 3×5=15e⁻（另 2 个 NO₃⁻ 不变价生成 HNO₃）。再逐项核对。

📌 逐项详解

A：×配平后 H₂O 计量数为 9（5NH₄NO₃ = 2HNO₃ + 4N₂↑ + 9H₂O），不是 6——A 错误，本题选 A。

B：√NH₄⁺ 中 N 升价（-3→0）、NO₃⁻ 中 N 降价（+5→0），同一物质既失电子又得电子，既是氧化剂又是还原剂。

C：√反应物只有一种 → 分解反应；有元素变价 → 氧化还原反应。

D：√氧化产物（5 个 NH₄⁺ → 5/2 mol N₂）与还原产物（3 个 NO₃⁻ → 3/2 mol N₂）物质的量之比 = 5/2 : 3/2 = 5 : 3。

⚠ 易错提醒

⚠ ①NH₄NO₃ 中两个 N 价态不同（-3 和 +5），不能把 NH₄NO₃ 当成"单一 N 价态"整体算；②自身氧化还原中部分 NO₃⁻ 不变价（生成 HNO₃），只有 3/5 被还原；③D 项氧化产物与还原产物都是 N₂，必须按来源（NH₄⁺ / NO₃⁻）区分比例，这是最易错的一步。

📐 规律总结

✅ G22 归中特例·自身氧化还原三兄弟：NH₄NO₃（-3 与 +5 → 0）、KClO₃ 分解（Cl +5 → -1 与 +7？实际生成 KCl 与 O₂，是 O 变价）、Na₂O₂ 与 CO₂（O -1 歧化）。口诀："一物含两价，先分两侧标；部分不变价，配平后核对"——配平先行，比例后算。

过关6 · 滴定里的氧化还原——KMnO₄ 方程式怎么配
【讲义课时精练 T6】

NaNO₂ 是一种食品添加剂，它能致癌。酸性 KMnO₄ 溶液与 NaNO₂ 反应的离子方程式为 MnO₄⁻ + NO₂⁻ + H⁺ —→ Mn²⁺ + ____ + H₂O（未配平）。下列叙述正确的是（　　）
A反应后溶液 pH 下降 B通常用盐酸酸化高锰酸钾溶液 C方框中粒子为 NO₂ D当生成 1 mol Mn²⁺ 需消耗 2.5 mol NO₂⁻

显示四段详解
✅ 正确答案：D

🧭 思路点拨

先配平：MnO₄⁻ 中 Mn +7→+2 得 5e⁻；NO₂⁻ 中 N +3→+5 失 2e⁻。最小公倍数 10 → 2MnO₄⁻、5NO₂⁻，产物方框为 NO₃⁻（N 升价）。电荷守恒补 H⁺：左侧 -2-5=-7，右侧 2×(+2)-5=-1，需 6H⁺ 平衡；原子守恒得 3H₂O。完整式：2MnO₄⁻ + 5NO₂⁻ + 6H⁺ = 2Mn²⁺ + 5NO₃⁻ + 3H₂O。再逐项判断。

📌 逐项详解

A：×反应消耗 H⁺（6H⁺ 进反应物），c(H⁺) 减小，pH 增大而非下降。

B：×Cl⁻ 有还原性，会被 MnO₄⁻ 氧化（生成 Cl₂），酸化 KMnO₄ 应用稀硫酸，不能用盐酸。

C：×NO₂⁻ 中 N +3 被氧化为 NO₃⁻（+5），不是 NO₂（+4）。

D：√由 2MnO₄⁻ ~ 5NO₂⁻，生成 1 mol Mn²⁺ 需消耗 5/2 = 2.5 mol NO₂⁻。

⚠ 易错提醒

⚠ ①酸性 KMnO₄ 不能用盐酸酸化——Cl⁻ 被氧化产生干扰（这是高锰酸钾标液配制的经典考点）；②NO₂⁻ 中 N 是 +3 价（亚硝酸根），氧化产物是 NO₃⁻ 不是 NO₂；③"pH 下降/上升"要看 H⁺ 是消耗还是生成，配平后从系数判断，别凭感觉。

📐 规律总结

✅ G19 缺项配平 + 定量判断组合题套路：先完整配平得系数比，再逐项验证。KMnO₄ 氧化还原滴定（NaNO₂、Fe²⁺、H₂C₂O₄ 等）是广东卷实验/流程题高频背景，"2MnO₄⁻ ~ 5 还原剂 ~ 转移 10e⁻"的计量关系要背熟。
