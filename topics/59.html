① 淀粉在稀硫酸（或酶）作用下水解：糖类第一条方程式
📖 讲义 P＿＿ · 考点一「二糖和多糖」
显示答案
(C₆H₁₀O₅)ₙ ＋ nH₂O 稀硫酸→Δ nC₆H₁₂O₆（葡萄糖）
三要点：条件写「稀硫酸或酶」；产物只有葡萄糖一种（蔗糖水解才是两种）；n 前后配平nH₂O ↔ nC₆H₁₂O₆。
⚠ 淀粉、纤维素本身无醛基、不发生银镜反应——水解生成葡萄糖后才还原
② 乙烯加聚生成聚乙烯：加聚反应母题
📖 讲义 P＿＿ · 考点三「加聚反应」
显示答案
nCH₂=CH₂ 催化剂→Δ ⎡CH₂—CH₂⎤n（聚乙烯）
要点：打开双键，两个碳各伸出半键相互连接成链；产物只有高分子、没有小分子——这是加聚与缩聚的根本区别。
⚠ 聚乙烯链节里没有 C=C（双键加成时已打开）——「聚乙烯能使溴水褪色」是错的说法（天然橡胶才行）
③ 氯乙烯加聚生成聚氯乙烯：真题 2025 广东 T5 的考点本体
📖 讲义 P＿＿ · 考点三「加聚反应」
显示答案
nCH₂=CHCl 催化剂→Δ ⎡CH₂—CHCl⎤n（聚氯乙烯）
单体是氯乙烯 CH₂=CHCl，不是 CH₃CH₂Cl（那是氯乙烷，没有双键，不能加聚）。

二本讲核心知识点3分钟
  • ① 糖类三兄弟：单糖（葡萄糖 C₆H₁₂O₆ 多羟基醛、果糖多羟基酮——同分异构体）／二糖（蔗糖、麦芽糖 C₁₂H₂₂O₁₁——同分异构体）／多糖（淀粉、纤维素 (C₆H₁₀O₅)ₙ——通式相同但 n 不同，不是同分异构体）。⚑ 2022·T9B「葡萄糖与果糖互为同分异构体，都属于烃类」判✗——糖是烃的衍生物，不是烃
  • ② 葡萄糖的还原性（检验核心）：含醛基 → 银镜反应、与新制 Cu(OH)₂ 加热生成砖红色沉淀。蔗糖不含醛基（非还原糖）；麦芽糖含醛基可银镜；淀粉遇碘（I₂）变蓝。⚑ 2023·T10C 新制 Cu(OH)₂ 检验葡萄糖中醛基；2026·T10C 糯米淀粉可水解成葡萄糖
  • ③ 氨基酸：两性＋成肽：α-氨基酸通式 R—CH(NH₂)—COOH，含—NH₂（碱性）＋—COOH（酸性）；两分子氨基酸酸脱羟基、氨基脱氢缩合脱水，形成肽键 —CONH—。⚑ 广东六年零落点（氨基酸两性、肽键）——讲义内容了解概念即可，不刷题
  • ④ 蛋白质五性质（必考）：水解（最终产物氨基酸）、两性、盐析（物理·可逆·提纯）、变性（化学·不可逆·杀菌消毒）、浓 HNO₃ 显黄色、灼烧有烧焦羽毛气味。酶是蛋白质，高温失活。⚑ 六年四考：2024 丝绸是蛋白质／2025 MgCl₂ 盐析／2023 加热变性／2026 牛肉蛋白质成分类
  • ⑤ 加聚 vs 缩聚（一根主线）：加聚——含 C=C，只产高分子、无小分子；缩聚——单体双官能团，产高分子＋小分子（H₂O 等）。单体推断：凡双键四个碳、无双键两个碳；缩聚在酯基／肽键处断键。⚑ 四年四视角：2025 聚氯乙烯单体判✗／2024 酚醛树脂缩聚判✗加聚／2023 聚乳酸可降解／2024 T7C 橡胶硫化交联
  • ⑥ 绿色高分子暗线：可降解＝链节含酯键、能水解——聚乳酸（2023·T7B）可生物降解；酚醛树脂是缩聚不是加聚（2024·T13D）；顺丁橡胶硫化：C=C 打开与硫成二硫桥、线性变网状（2024·T7C）。

【例】淀粉水解情况的检验（讲义提升题）：甲乙丙丁四个方案，结论谁对谁错？
📖 讲义 P＿＿ · 「糖类的水解实验」

· 方案甲：水解液 → 加 NaOH → 加碘水，溶液不变蓝 → 结论「完全水解」

· 方案乙：水解液（未中和，含稀硫酸）→ 加银氨溶液 → 无银镜 → 结论「尚未水解」

· 方案丙：水解液 → 加 NaOH 中和 → 加银氨溶液 → 有银镜 → 结论「已经水解」

· 方案丁：水解液 → 加 NaOH 中和 → 加碘水变蓝、又有银镜 → 结论「部分水解」

显示答案
甲、乙错；丙、丁对
甲错——先加 NaOH 后加碘水，I₂ 与 NaOH 反应掉了，不变蓝不能证明淀粉没了。
乙错——银氨溶液被稀硫酸破坏，无银镜不能证明没有葡萄糖。
丙对——中和后银镜成功 → 有葡萄糖 → 淀粉已水解。
丁对——变蓝（有淀粉）＋银镜（有葡萄糖）→ 部分水解。
✅ 检验两路（必背）：验葡萄糖 → 先 NaOH 中和、再加银氨/新制 Cu(OH)₂；验淀粉 → 直接加碘水（不能有 NaOH）
辨析 1凡是能溶于水且具有甜味的物质都属于糖类（　　）
×　糖的界定看结构（多羟基醛/酮及其脱水缩合物），不看甜味。糖精有甜味不是糖；淀粉没甜味却是糖。
辨析 2葡萄糖和果糖、蔗糖和麦芽糖、淀粉和纤维素均互为同分异构体（　　）
×　前两对是（分子式相同）；淀粉和纤维素通式都是 (C₆H₁₀O₅)ₙ，但 n 值不同，分子式不同，不是同分异构体。
辨析 3用新制 Cu(OH)₂ 可鉴别麦芽糖和蔗糖（　　）；1 mol 麦芽糖水解得到 1 mol 葡萄糖和 1 mol 果糖（　　）
√；×　麦芽糖含醛基能生成砖红色沉淀、蔗糖不能——可鉴别（√）。麦芽糖水解只得葡萄糖（2 mol），得葡萄糖＋果糖的是蔗糖（×）。

考点② · 氨基酸与蛋白质：两性、盐析与变性（约9分钟）

📖 讲义 P＿＿ · 考点二「氨基酸　蛋白质　核酸」

▲ α-氨基酸通式（讲义原图）：同碳上连 —NH₂ 和 —COOH，天然蛋白质都由 α-氨基酸构成

· 两性：—COOH 显酸性（与 NaOH 反应）、—NH₂ 显碱性（与 HCl 反应成盐）——氨基酸既能跟酸又能跟碱反应。

· 成肽反应：一个氨基酸的 —COOH 与另一个的 —NH₂ 脱水缩合 → 肽键 —CONH—；二肽含 1 个肽键。多肽水解找肽键断开、C 补羟基、N 补氢即得氨基酸。

▲ 蛋白质五性质（讲义原图）：水解 / 两性 / 盐析 / 变性 / 显色 / 燃烧

对比项盐析变性
条件轻金属盐（Na₂SO₄ 等浓溶液）加热、强酸碱、重金属盐（CuSO₄ 等）、紫外线、乙醇、甲醛
可逆性物理变化 · 可逆化学变化 · 不可逆

【抢答】鸡蛋清溶液中加入：①饱和 Na₂SO₄ 溶液 ②CuSO₄ 溶液 ③蒸馏水后加热——各是什么变化？
📖 讲义 P＿＿ · 「蛋白质的性质」
显示答案
①盐析（物理·可逆·可提纯）　②变性（化学·不可逆）　③变性（加热不可逆）
记忆钩子：「轻盐析、重金变」——轻金属盐（Na₂SO₄、(NH₄)₂SO₄）→ 盐析；重金属盐（CuSO₄、Pb 盐）→ 变性。
⚠ 高温消毒、酒精消毒、紫外线杀菌全是「变性」原理——变性才是不可逆的
辨析 4用灼烧的方法可以区分蚕丝和人造纤维（　　）
√　蚕丝是蛋白质，灼烧有烧焦羽毛气味；人造纤维没有。同款题：区分纯毛线与合成纤维。
辨析 5温度越高，酶的催化效率越高（　　）
×　酶是蛋白质，温度过高会变性失活，催化效率反而下降。「高温灭活」与「温度升速率加快」混在一起考。
辨析 6用浓 Na₂SO₄、CuSO₄ 溶液均能使蛋清发生盐析，进而分离提纯蛋白质（　　）
×　Na₂SO₄ 盐析√；CuSO₄ 是重金属盐 → 变性，不可逆，不能用于提纯。判断题最爱的「一半对一半错」句式。

考点③ · 合成高分子：加聚、缩聚与单体推断（约7分钟）

📖 讲义 P＿＿ · 考点三「合成高分子」

· 三个概念：单体（聚合用的小分子）→ 链节（高分子中重复的最小结构单元）→ 聚合度 n（链节个数）。高分子的分子量是 n 的平均值，高分子都是混合物。

· 加聚：单体含 C=C（或 C≡C），打开双键连成链，无小分子副产物——聚乙烯、聚氯乙烯、聚丙烯、天然橡胶（聚异戊二烯，链节保留 C=C、能使溴水褪色）。

· 缩聚：单体含两个官能团（二元酸＋二元醇、羟基酸、氨基酸），缩合出高分子＋小分子（H₂O 等）——涤纶（聚酯）、尼龙（聚酰胺）、酚醛树脂（热固性塑料）。

📢 单体推断口诀（讲义原话）

凡双键，四个碳；无双键，两个碳——画线断键，半键闭合、单双键互换。
缩聚产物：找酯基 / 肽键，在 C—O 或 C—N 处断键，碳补 —OH、氧氮补 —H。

【抢答】⎡CH₂—CH₂—O⎤ₙ 的单体？⎡CH₂—CH=CH—CH₂⎤ₙ 的单体？
📖 讲义 P＿＿ · 「高聚物单体的推断方法」
显示答案
① 链节含 —O— → 缩聚（聚醚/聚酯类），断 C—O 键、C 补 —OH、O 补 —H → 单体乙二醇 HOCH₂CH₂OH（若为 —COO— 型则得二元酸＋二元醇）。② 全碳链、链节有 C=C → 加聚（异戊二烯型），无双键处两个碳一段断开 → 单体 CH₂=CH—CH=CH₂（1,3-丁二烯）。
判断流程：先看链节有没有杂原子（O/N）→ 有则是缩聚、无则是加聚；加聚按口诀断键，缩聚找酯基肽键断键。
辨析 7加聚反应单体有一种，而缩聚反应的单体应该有两种（　　）
×　加聚单体可一种（乙烯）也可两种；缩聚单体可两种（二元酸＋二元醇）也可一种（羟基酸、氨基酸自身缩聚）。「应该」二字就是坑。
辨析 8聚氯乙烯和酚醛树脂都是热固性塑料（　　）；聚乙烯薄膜可用于包装食品，聚氯乙烯薄膜不可（　　）
×；√　酚醛树脂热固性、聚氯乙烯是热塑性（受热软化可重塑）。聚氯乙烯含氯、增塑剂有毒，不能包装食品——食品袋用聚乙烯。
辨析 9橡胶的老化实质上发生的是酯化反应（　　）
×　天然橡胶（聚异戊二烯）链节含 C=C，老化是被氧气氧化（双键被破坏变脆），不是酯化。

考点④ · 绿色高分子：可降解＝酯键＋单体互推（约6分钟）

📖 讲义 P＿＿ · 考点三「合成高分子」· 能力层主线

⚑ 「可降解」的暗线是酯键：聚乳酸可生物降解＝链节含酯键、体内能水解（2023·T7B）——把「绿色高分子」的考法归到「含什么键」上，聚酯、PHA、聚硫酸酯同解（衔接第58讲酯的水解）。

缩聚产物的链节里出现 —COO— 或 —CONH— 时，单体怎么找？（想一想 2022·T21(6)「写高分子Ⅷ的单体」的钥匙）
显示答案
在酯键/酰胺键处断键，碳补 —OH、氧/氮补 —H：
· 链节含 —COO— → 单体是羟基酸（自身缩聚）或二元酸＋二元醇；
· 链节含 —CONH— → 单体是氨基酸或二元酸＋二元胺；
· 酚醛树脂记「苯酚邻对位＋甲醛」。
✅ 加聚 vs 缩聚一句话：链节全碳、有 C=C 段 → 加聚（凡双键四个碳）；链节带杂原子（O/N）→ 缩聚（找键断）
