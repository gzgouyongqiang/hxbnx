物质 A(g) 可同时转化为它的同分异构体 B(g) 和 C(g)，其反应过程的能量变化如图 a，某温度下，测得恒容密闭容器中各组分浓度 c 随时间 t 的变化如图 b，则
图a：反应过程的能量变化；图b：各组分浓度随时间变化
A. t1 时，体系中物质的质量：m(A)=2m(B)
B. 图 b 中数据满足关系：2z＞x+y
C. 体系中，反应 A(g)⇌C(g) 先达到平衡
D. 体系平衡后，升高温度，B 的体积分数增加
1
🔍 先读图 a：两条曲线一实一虚，峰高和终点高低各自说明什么？
能量图读三件事：峰高=活化能（速率），终点=稳定性，全程=反应热 🔴 实线 A→B：峰高（Ea 大、慢）＋ B 能量低（放热多、稳定） 🔴 虚线 A→C：峰低（Ea 小、快）＋ C 能量高（不稳定） C 是「动力学产物」（生成快）；B 是「热力学产物」（平衡时多）——快≠多！
2
💭 图 b 三条曲线，谁是谁？(t₂, z) 这个点特殊在哪？
对号入座：降者是反应物，升者是产物 下降曲线 = A；先陡后低平 = C（快而少）；先缓后高平 = B（慢而多） (t1, y) 在 A 上 → c(A)=y；(t1, x) 在 B 上 → c(B)=x (t2, z) 是两条产物曲线的交点 → c(B)=c(C)=z（题眼！）
3
💭 A、C、D 三个选项，逐个用图「怼」回去
A：m(A)=2m(B) 即 y=2x？读图 y 与 x 明显不成 2 倍 → A ✘ C：A⇌C 先达平衡？两反应共用 A，同一容器只有一个平衡态，各组分同时不变 A→C 快≠先达平衡，偷换概念 → C ✘ D：升温向吸热方向（A→C）移动，B 被「退回」A → B 体积分数减小 → D ✘
4
💭 正面攻 B：2z＞x+y 怎么证？用守恒！
恒容恒温，物料守恒：c(A)+c(B)+c(C)=c₀（不变） t1 时：c₀ = y + x + c(C)1 t2 时：c₀ = 2z + c(A)2（两产物都等于 z） 两式相减整理：2z＞x+y ⟺ c(C)1＞c(A)2，读图成立 ✓ ✅ 答案 B
5
💭 复盘：双图题的通法是什么？
✔ 第一步读能量图：峰高速率、终点稳不稳、全程定反应热，先判「动力学 vs 热力学」 ✔ 第二步读浓度图：降=反应物、升=产物；交点=两物质浓度相等（往往是题眼） ✔ 第三步证数量关系：物料守恒是万能钥匙，把 x、y、z 挂到守恒式上再比较
