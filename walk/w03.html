A. 物质a：2-溴丁烷｜溶剂b：乙醇｜Ⅰ中发生消去反应；Ⅳ中溶液褪色，发生取代反应

D. 物质a：溴乙烷｜溶剂b：乙醇｜冷却后向烧瓶中加过量稀硝酸，再加 AgNO3 溶液，生成沉淀
1
🔍 先审题！装置四段各司其职，溶剂 b 为什么是关键？自己先说一遍
装置分工：先看每个瓶子在「查」什么 🔴 Ⅰ（烧瓶）：NaOH 溶液＋溶剂 b＋碎瓷片、加热 → 反应发生器 🔴 Ⅱ（水）：接蒸气，滴酸性 K2Cr2O7 → 查水溶性还原性物质 🔴 Ⅲ（石英棉＋酸性 KMnO4）、Ⅳ（溴的 CCl4） → 双双查不饱和烃 🔴 溶剂 b：是水→Ⅰ中取代（水解）；是乙醇→Ⅰ中消去。一把定反应类型！
2
💭 A 选项：2-溴丁烷/乙醇。Ⅰ中真能消去吗？Ⅳ中褪色又是什么反应？
A：NaOH 醇溶液＋加热 → 消去 2-溴丁烷 →（消去）→ 丁烯，Ⅰ中确为消去反应 ✓ 但Ⅳ中溴的 CCl4 褪色，是烯烃的加成反应，不是取代！ 「褪色=取代」这口锅，加成不背 → A ✘
3
💭 B 选项：换成水做溶剂，产物和现象怎么变？
B：NaOH 水溶液＋加热 → 水解（取代） 2-溴丁烷 →（水解）→ 2-丁醇，Ⅰ中产物判断 ✓ 但 2-丁醇是饱和醇：不能使酸性 KMnO4、溴的 CCl4 褪色 「Ⅲ中石英棉和Ⅳ中溶液均褪色」 → B ✘
4
💭 C 选项：溴乙烷/水，K₂Cr₂O₇ 注入Ⅱ中会变色吗？
C：溴乙烷水解 → 乙醇＋NaBr CH3CH2Br →（水解）→ CH3CH2OH 乙醇挥发进入Ⅱ，酸性 K2Cr2O7（橙红）被还原 → 变绿 「颜色无明显变化」与事实相反 → C ✘
5
💭 只剩 D 了。检验卤离子，为什么要「先加过量稀硝酸」？
D：溴乙烷/乙醇 → 消去生成乙烯＋NaBr 冷却后加过量稀硝酸：中和掉 NaOH（否则 Ag+ 会生成 Ag2O 干扰） 再加 AgNO3：Br−＋Ag+ = AgBr↓（淡黄色）→ D ✓ ✔ 口诀：查 X−三步——冷却、酸化、加银盐，酸化是双保险，省了必错 ✅ 答案 D
