金(Au)是一种战略性金属。从某金精矿（含金、银、Sb2S3、FeS2、SiO2 和 MgO 等）中提取金并综合利用部分物质的一种工艺如下。
提取金工艺流程图
已知：Au(Ⅲ) 和 Ag(Ⅰ) 在一定条件下均可与 Cl− 形成可溶于水的配离子。
氢氧化物 Ksp(298K)：Fe(OH)3 = 2.8×10−39｜Fe(OH)2 = 4.9×10−17｜Mg(OH)2 = 5.6×10−12

🔍 先读流程：矿粉进去，金出来，中间有几道关？每关在搬什么？
流程四关：浸取 → 沉锑 → X（浸金银）→ 沉金 🔴 浸取：盐酸＋氧化剂，把 Sb 变成 [SbCl4]− 进溶液 🔴 沉锑：铁粉上场，得 Sb 单质（→AlSb 光电子材料），滤液 1 还能电解回收 🔴 X：HCl＋H2O2 分步浸出 Ag、Au；沉金：Na2SO3/NaOH 把金「摁」出来 🔴 （1）研磨成粉 → 增大反应物接触面积，提高浸取速率（送分空，别丢！）
2
💭 （2）「沉锑」反应里，还原剂是谁？电子怎么转？
沉锑：[SbCl4]− 中的 Sb(Ⅲ) → Sb(0)，得电子被还原 加入的铁粉失电子：Fe → Fe2+，作还原剂 ✅ 还原剂为 Fe（或铁粉） 💡 伏笔：滤液 1 里的 Fe2+ 正是下一步电解要回收的——「沉锑试剂回收利用」说的就是它
3
💭 （3）① 电解池图1：阴极上谁放电？铁怎么回来？（附电解池图）
电解目的：把 Fe2+ 变回 Fe 粉，循环沉锑
图1：电解池（阴离子交换膜）
阴极（还原）：Fe2+ + 2e− = Fe 阳极（氧化）：Fe2+ − e− = Fe3+（题目说忽略生成气体的反应） ✅ 阴极反应式：Fe2++2e−=Fe
4
💭 （3）② 防沉淀：阳极室 OH⁻ 最多能给多少？列算式！
阳极室里 Fe2+ 会被氧化成 Fe3+，要防的是 Fe(OH)3 析出 初始 c(Fe2+)=1.4 mol/L → 全部氧化后 c(Fe3+) 最大 1.4 mol/L 不析出条件：Q = c(Fe3+)·c3(OH−) ≤ Ksp[Fe(OH)3] = 2.8×10−39 c(OH−) ≤ ∛(2.8×10−39 / 1.4) mol/L（= ∛(2×10−39)） ✅ 最终阳极室 c(OH−) 应不大于 ∛(2.8×10−39/1.4) mol/L

💭 （4）「X」怎么设计？图2两条曲线在告诉你什么？（附浸取率图）
目标：金的提取率和纯度都要——先除 Ag 再提 Au，别混
图2：Au、Ag浸取率随c(H₂O₂)的变化
🔴 Ag 曲线：c(H2O2)=x1 时浸取率已≈100%，而 Au 几乎没动 🔴 Au 曲线：要到 x3 附近才冲到 100%（x2 处开始爬升） ✔ 先控 c(H2O2)=x1 mol/L，与 HCl 浸出 Ag 后过滤除去 ✔ 再控 c(H2O2)=x3 mol/L，与 HCl 浸出 Au，过滤（Au 以 [AuCl4]− 进滤液 2）

💭 （5）沉金方程式：HSO₃⁻ 出场，Au(Ⅲ) 去哪了？
沉金 = [AuCl4]− 里的 Au(Ⅲ) 被还原成 Au 单质析出 还原剂是 Na2SO3 在弱酸性条件下的 HSO3−：S +4 → +6（SO42−） NaOH 调控弱酸性：酸性太强 HSO3− 变 SO2 跑掉，太强又变 SO32− ✅ 2[AuCl4]− + 3HSO3− + 3H2O = 2Au↓ + 3SO42− + 8Cl− + 9H+
